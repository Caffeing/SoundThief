# 우편 분류소 — 아직 보내지 마세요!

gganwoor의 우편 스테이지 그레이박스. main의 공통 플레이어·소리·경비·아이템 코어를 사용한다. 이번 편지 탐색 기능은 이 폴더의 코드와 씬에만 추가했다. 공통 코드·프리팹·SoundRules·공용 빌드 씬 목록은 수정하지 않는다.

## 실행과 조작

Unity 6000.3.19f1에서 `PostalDepot.unity`를 열고 `PostalDepot Local Playtest.asset` 로컬 Build Profile을 활성화해 Play한다. 프로필은 macOS용이며 다른 플랫폼은 별도의 로컬 프로필에 씬을 등록한다.

- WASD 이동, 마우스 시점, F 상호작용, E 추출, Q 주입, Ctrl 웅크리기.
- Tab 의뢰, Esc 일시정지, R 재시작. 투척은 계속 비활성화다.
- 편지에 F: 내용 읽기. 읽기 창의 버튼 또는 Enter: 현재 편지 회수. 버튼 또는 Esc: 닫기.
- 읽는 동안에는 시간·경비·소리 보유 시간이 멈춘다. 창을 닫으면 조작과 시간이 복구된다. 읽기 창에서는 Enter/Esc와 버튼을 사용하고, 일반 조작은 닫은 뒤 사용한다.

## 의뢰와 찾기

의뢰인 윤서진은 김하늘에게 노란 우산을 돌려주지 않았다고 화내는 편지를 보냈다. 우산을 집에서 찾았으니 발송 전에 그 편지를 회수해 달라는 가벼운 의뢰다.

1. 접수실의 직원 열쇠와 분류실 문은 기존 무음 개문 경로다. 오른쪽 하역 통로로 우회할 수도 있다.
2. 분류표를 확인하면 개인 편지가 발송 대기실 A~C 선반에 있다는 안내가 나온다. 정확한 편지나 선반 번호는 알려주지 않는다.
3. 발송실의 선반은 앞뒤 2열, 총 6개다. 쌓인 우편물 대부분은 장식이며 F 안내가 표시되는 편지 4통을 읽을 수 있다.
4. 각 편지는 수취인·발신인·내용이 다르다. 이름이나 ‘우산’이라는 단어만으로 결정하지 말고 의뢰의 사연과 대조한다. 읽기만 해서는 소지품이 바뀌지 않는다.
5. 회수 가능한 편지는 한 통이다. 다른 편지를 회수하면 기존 편지를 교체한다. 편지 오브젝트는 남아 있으므로 다시 읽고 바꿀 수 있다. 오답을 고르는 것만으로 벌이나 재시작은 발생하지 않는다.
6. 분류표 확인 기록과 의뢰에 맞는 편지가 있어야 앞마당 출구 F로 완료된다. 오답 편지로는 탈출이 거절된다.

발송실의 분류 손잡이는 1등급 원천이다. 빈 우편함에 주입하고 분류실 입구의 벽 뒤로 물러나 경비가 자리를 떠나기를 기다린다. 경비와 거리를 두고 접근하고, 회수 후 오른쪽 통로로 돌아올 수 있다. 잠든 경비와 접촉해도 재시작된다. 능력 사용 이력 자체를 완료 조건으로 강제하지는 않는다.

## 구현과 편집

- `PostalLetter`: 편지별 ID, 수취인, 발신인, 본문, 목표 여부를 Inspector에서 편집한다. 읽은 상태는 실행 중에만 유지된다.
- `PostalLetterReader`: 우편 씬의 F 입력을 먼저 처리해 편지가 즉시 수집되지 않도록 한다. 다른 대상은 기존 `ThiefInteractable.Interact`로 위임한다. F 처리 프레임에는 공통 플레이어 입력을 잠시 중단하고 프레임 끝에 복구하며, 읽는 동안은 기존 MissionDirector 일시정지를 소유한다.
- 읽기 창은 런타임 uGUI Canvas로 생성된다. 기본 도형과 임시 색만 사용하고, 공통 HUD·프리팹 원본에 Apply하지 않는다.
- `PostalBriefing`: 분류표 안내와 OS 한글 글꼴 연결을 담당한다. 글꼴 파일은 복제하거나 배포하지 않으므로 정식 배포용 글꼴은 후속 준비가 필요하다.
- `PostalSearchAuthoring.Apply Letter Search Layout`: 해당 씬의 확장 배치·선반·편지 기본 본문을 다시 적용하고 NavMesh를 갱신한다. 실행하면 이 기능의 배치와 편지 내용이 기본값으로 다시 작성된다. 수동 편집한 뒤에는 필요할 때만 실행한다.
- `Create Or Open Graybox`는 기존 씬이 있으면 열기만 한다. 새로 생성할 때는 편지 탐색 배치를 함께 적용한다.
- 정답 위치는 고정이다. 현재 `Letter B`의 편지 #03이 목표이며, #01/#02/#04는 내용을 대조하기 위한 후보다. 이 정보는 제작·검증용이며 읽기 창에 정답 표시는 하지 않는다.

## 검증

2026-10-30 전체 PlayMode 검사 51/51 통과, 그중 우편 검사 12/12 통과. 기존 검사에 서로 다른 본문·읽기와 수집의 분리·오답 교체·오답 탈출 거절·읽기 중 타이머 정지와 조작 복구·벽 차폐 검사를 포함한다.

실제 키보드/마우스 입력으로 네 편지 읽기, 마우스 회수 버튼, Esc 닫기, 오답 탈출 거절, 소리 보유 중 읽기, 정답으로 교체 후 탈출까지 확인했다. 알려진 맵을 자동 조향한 검사이므로 사람의 초회 탐색과 재미 검토는 별도로 필요하다. 상세 로그·화면·최종 전체 검사 결과는 저장소 바깥 `work/postal-letter-search-2026-10-30/`에 보존한다.

커밋과 푸시는 사용자가 진행한다.
