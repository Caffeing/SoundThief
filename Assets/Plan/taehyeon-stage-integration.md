# taehyeon 스테이지 → HMM 적용 및 시스템 비교

기준일: 2026-10-30. 비교 원본은 HMM `22fba57`과 원격 `origin/taehyeon` `9cba1de`다. `feat/taehyeon-map-stage`는 이번 가져오기 원본으로 사용하지 않았다. 작업 브랜치는 HMM을 유지하며 커밋·푸시·통째 병합을 수행하지 않는다.

## 적용 원칙

HMM의 길드·의뢰 전환·문서 UI를 기준으로 보존하고, taehyeon의 ManorPrototype 씬과 필요한 모델·소리·재질·셰이더·런타임 기능을 선별 적용한다. 원본 브랜치의 Guild 삭제, 의뢰 시스템 단순화, 길드 API 제거는 적용하지 않는다. 원본 스테이지의 이전 배치 백업 씬도 실행 대상에 추가하지 않는다.

기존 HMM 길드 씬, MissionDirector, GuildContractTable, GuildContractView, ContractPageCurl, PrototypeRules 및 빌드 씬 목록은 해시로 보존을 확인한다. GuildPractice는 동일한 능력을 가르치도록 안내 문장만 갱신했다. 공유 Runtime은 양쪽 기능을 통합하므로 일부 파일은 변경한다.

## 통합 중 확인한 문제와 조치

- Runtime 전체 교체 시 길드 API와 상호작용 enum 값이 사라질 수 있어 HMM enum 0~8과 길드 어댑터를 유지했다.
- 연습 중 접촉이 경비 갱신을 중단시키지 않도록 HMM의 길드 예외를 유지했다. 새 순찰/지속음 상태까지 연습 초기화가 정리하도록 보완했다. 로비에서는 연습 경비가 소리·기절에 재활성화되지 않는다.
- 원격 씬은 이전 ManorShortHallNavMesh를 참조하고 있어 현재 배치와 맞지 않았다. 실제 PhysicsColliders 기준의 별도 ManorTaehyeonIntegratedNavMesh를 생성하고 연결했다. 길드 이동망과 전역 에이전트 설정은 변경하지 않는다.
- 문 회전 직후 물리 경계가 이전 위치에 남는 프레임을 확인해 Physics.SyncTransforms로 즉시 동기화한다.
- 원격 테스트에 이동 전 갑옷/출구 좌표가 남아 있어 실제 대상 위치를 사용하는 접근 검사로 갱신했다. 경비를 끄거나 보유 시간을 무한대로 바꿔 통과시키지 않는다.
- 새 에셋 의존성을 GUID로 추적하고 필요한 LFS 바이너리와 라이선스를 함께 가져왔다. 전체 ThirdParty 팩을 병합하지 않았다.

## 구현상의 한계와 다음 검토

- 현재 청각은 소리와 청자 사이의 직선상 지정 차폐체로 가청 범위를 조정한다. 회절·반사·복잡한 방별 음향 전파는 모델링하지 않는다. 등급 자체는 정수로 유지한다.
- 길드 연습과 저택은 같은 지연 주입·짧은 연결 효과를 사용한다. 연습장 안내에도 지연 출력을 명시했다.
- 이동·접촉·소리·시야를 켠 경로 검사는 완주 가능성을 검증한다. 사용자에게 해법이 보이는지, 경비가 공정하게 느껴지는지, 운반이 재미있는지는 별도 플레이 평가가 필요하다.
- 투척은 양쪽 현재 설정에서 비활성이므로 이번 통합으로 활성 능력에 추가하지 않았다.
- **서재 물병을 이용한 대체 유인 완주는 아직 보장하지 않는다.** 원본 브랜치의 해당 경로 테스트는 물병의 최신 위치·벽 차폐·순찰에 맞지 않았다. 접촉 실패 또는 실제 유인 없이 경로가 진행되는 현상을 확인했다. 게임의 벽·경비·시간을 바꿔 이 가정을 강제하지 않고, 물병의 독립 주입·원음 보존·지연 출력·관계 복구를 검사하는 테스트로 교체했다. 실제 경비를 켠 시계 유인과 인장 절도 후 탈출 검사는 별도로 유지한다. 물병 경로의 배치·소리 선택·진입 시점은 후속 레벨 검토 항목이다.

## 1차 통합 검증 이력

- Unity 6000.3.19f1의 연결된 Editor/Pipeline에서 컴파일 성공. 최종 PlayMode **68/68 통과**, 실패·건너뜀 0(194.22초).
- 길드 문서 입력 잠금·ESC·양방향 문서 순환·깜빡임 회귀, 선택 연습·초기화, 수락→출구 출발→새 저택→성공→길드 문 복귀를 포함한다.
- 소리 차폐, 원음 보존, 지연 출력, 순간음/지속음 조사, 순찰, 문 시각/충돌 정렬, 아이템 조건, 접촉 재시작, 자폭·패닉·일시정지를 확인했다. 투척 검사는 복제한 테스트 규칙에서만 활성화한 보존 검사다.
- 실제 경비·충돌·운반 속도·제한 시간을 유지한 시계 유인→서재 열쇠 회수 및 두 열쇠→식당 인장→출구 완주가 통과했다. 물병은 독립 주입 기능 검사이며 대체 유인 완주 통과로 세지 않는다.
- StageContext 검증 오류 0. 누락 스크립트·재질·MeshFilter/SkinnedMeshRenderer 메시·오류 셰이더 0.
- 원본 스테이지 Transform 1,081개의 위치·회전·크기 변화 0. HMM 길드 핵심 8개 파일 해시 일치. 빌드 첫 씬 Guild 유지.
- 실제 Play에서 길드→저택 수락 이월과 프레임/게임 시간 증가를 확인하고 Game View HUD와 한글 렌더를 검토했다. 종료 후 길드 씬을 변경 없이 편집 모드로 열어 두었다.
- 원본 ThirdParty FBX 두 곳에 자기 교차 면 제외 경고가 남아 있다(테이블 EA03_Prop_Town_Tabble_01a, 인물 Villager_Male_Vest_02c). 가져온 에셋의 이름 불일치 경고 두 건은 수정했다. 컴파일·런타임 오류는 0이다.
- HMM HEAD는 작업 전과 같은 22fba57이고 스테이징·커밋·푸시를 하지 않았다.

## 후속 결정 — 길드·의뢰 외 taehyeon 방식 수용

2026-10-30 사용자의 명시적 결정에 따라 주입·청각 전달·소리 조사·경비·문·절도·스테이지는 taehyeon 방식을 공통 기준으로 사용한다. 길드 전용 즉시 출력과 상시 연결선 예외를 제거했다. 연습장도 주입 후 대기→출력과 능력 사용 때의 짧은 연결 효과를 사용한다. 손을 비운 직후 이동 제한 해제·재추출, 원음 보존·차폐·순찰·자동 문·절도 소음은 taehyeon 동작을 따른다.

SoundEmitter와 SoundRules는 taehyeon 원본과 일치한다. 공유 파일에 남긴 차이는 HMM 길드/의뢰용 입력·상태·초기화 연결과 문 물리 동기화 등의 통합 수정이다. 선택 연습·문서 열람·의뢰 수락→출구 출발→성공 후 길드 문 복귀는 HMM을 유지한다. 기존 길드/저택별 보유 시간 데이터는 taehyeon에도 있는 구성이므로 그대로 사용하며, 별도 즉시 출력 분기는 없다. 투척은 taehyeon 현재 설정과 같이 비활성이다.

최종 검증은 `Assets/Plan/taehyeon-policy-adoption.md`와 `Artifacts/TaehyeonPolicyAdoption/`을 따른다. 위 68개 기록은 1차 통합 이력이며, 후속 변경에는 연습장 지연 주입·연결선 회귀 검사를 추가했다. 물병 대체 유인 경로의 검증 한계와 원본 FBX 경고는 앞 절과 같다.
