# taehyeon 최신 반영 — 7b5cc11

2026-10-30. 원본은 정확한 `origin/taehyeon` `7b5cc11a0aaa0116df52d98d83164ae8b659f7a3`이며 `feat/taehyeon-map-stage`는 사용하지 않았다. 이전 적용 기준 `9cba1de` 이후 두 커밋의 변경 1,363개 파일을 현재 HMM 작업 트리에 반영했다. 추가 LFS 에셋 180개(약 57.7MiB)는 크기·SHA-256을 확인해 가져왔다. 브랜치 변경·스테이징·커밋·푸시는 하지 않았다.

## 반영 기준

충돌하는 플레이 동작과 HUD는 최신 taehyeon을 우선했다. 현재 미커밋 변경과 교체 전 파일은 `Artifacts/TaehyeonUpdate-7b5cc11/before/`에 보관했다. 길드·의뢰·완료 이력·의뢰별 재수락 정책은 유지하고 새 기능과 연결했다. 현재 스테이지 1은 계속 재수락 불가능이다.

## 주요 변경

- 최신 저택 씬·가구 충돌·이동망과 PC/모바일 소리 스캔 Renderer Feature를 적용했다. 이전 통합용 이동망을 다시 굽지 않고 최신 원본을 사용한다.
- 운반은 느린 이동을 유지하며 자동으로 앉지 않는다. Ctrl로 실제 CharacterController 높이·카메라·시야각을 부드럽게 변경한다. 낮은 천장 아래에서 기립을 막는다.
- 경비의 부드러운 회전·추격 속도 구분·문 개방과 통과·발소리·시야 표시를 반영했다. 이미 잠금 해제된 문만 경비가 열 수 있다.
- 손·운반 소리 표시와 시간 초과 연출, 플레이어 발소리, 원래 소리/발소리에 연동되는 소리 지형 스캔을 반영했다.
- 목표/일반 알림을 잠깐 표시하는 HUD, 운반·기절 상태 패널, 상세 의뢰창, 별도 일시정지 화면을 반영했다.
- 최신 런타임·리소스·에셋 팩·데모·브랜치 기획/검사 자료도 함께 가져왔다. 원본 검사 자료는 taehyeon의 이력이며 이번 HMM에서 실행한 결과를 뜻하지 않는다.

## 길드 연결

HMM의 문서 넘김·입력 잠금, 의뢰 수락 후 출구 출발, 성공 후 길드 문 귀환, 완료 표시·재수락 불가능 옵션, 선택 연습·초기화를 유지했다. 새 자세와 경비의 문/회전 상태가 초기화 흐름에 남지 않도록 연결했다. 새 HUD에서 문서 열람 중 일반 HUD를 숨기고 길드 연습 안내를 유지한다. 최신 저택 MissionDirector에는 성공 후 길드 복귀 연결만 추가했다.

## 확인 범위

사용자 요청에 따라 Play 진입·자동 테스트·완주·화면 캡처를 실행하지 않았다. 코드 충돌/정적 차이, LFS 데이터, Unity 자동 컴파일과 씬 연결만 확인했다. 컴파일 오류 0이며 StageContext 검증 메시지는 없다. 길드 핵심 파일 해시와 최신 원본 저택의 위치·회전·크기를 보존했다. 플레이 동작을 이번 실행으로 검증했다고 주장하지 않는다.
