# 공통 스테이지 기반 실행 안내

## 2026-10-30 상시 강조 제거 후속

소리 사물은 평소에 강조하지 않는다. 상호작용 거리에서 직접 조준한 사물 하나에만 얇고 반투명한 황동색 테두리를 0.15초에 걸쳐 표시하고, 시선을 떼면 사라진다. 무음·주입 상태는 기존 상호작용 안내와 실제 소리 반응으로 읽는다. 파란색 테두리와 평상시 연결선은 제거하고, 추출·주입에 성공한 직후에만 0.3초 연결 효과를 사용한다.

경비 시야는 상시 표시하지 않는다. 10m 이내에서 벽에 가리지 않은 활동 중 경비를 약 0.4초 동안 직접 바라보면, 현재 시야가 바닥에 옅은 적갈색으로 1.4초 동안 나타나고 사라진다. 계속 바라봐도 상시 표시로 이어지지 않는다. 시선을 0.25초 이상 뗐다가 다시 관찰하면 재확인할 수 있다. 벽·가구·닫힌 문 차폐와 수면·기절·패닉 시 숨김을 유지한다. 실제 감지 판정은 바꾸지 않는다.

현재 한국어 하이어라키와 짧은 검증 결과는 hierarchy-and-feedback.md를 따른다. 아래의 이전 청록색/상시 시야 기록은 변경 이력이다.


현재 개발 목표는 공통 기반이다. 제작 방법은 stage-authoring.md를 따른다.

Assets/Scenes/Stages/FrameworkExample.unity를 열어 Play한다. 구리 열쇠를 F로 얻고 문을 열어 두 유물을 모두 회수한 뒤 시작 위치 뒤의 출구에서 F로 완료한다. R로 같은 씬의 전체 상태를 초기화한다. 기존 ManorPrototype도 직접 실행하면 의뢰가 시작된다.

길드와 훈련장은 다른 팀원 담당이다. 기존 길드 프로토타입과 전용 기획서는 삭제했다.

## 의뢰 플레이

**1스테이지 개편 중:** 현관 열쇠를 얻어 정문으로 들어간 뒤 왼쪽 서재의 식당 열쇠를 찾는다. 중앙 홀 오른쪽 식당의 앞문과 뒷문은 모두 식당 열쇠가 필요하다. 인장을 획득한 뒤 두 문 중 하나를 통해 현관으로 돌아온다. 서재 시계와 식당 갑옷, 문에 소리를 주입할 수 있고 각 방에는 경비가 있다.

1. 시작 지점 왼쪽 받침대 위의 열쇠를 조준하고 F로 획득한다.
2. 정면의 잠긴 문 가까이 가서 E로 `열쇠 ↔ 자물쇠` 관계를 추출한다. 청록 연결과 무음 표시, 보유 타이머를 확인한다.
3. F로 문을 연다. 문 통과 시에도 무음 관계와 보유 타이머는 유지된다.
4. 왼쪽 서재에서 경비를 피해 식당 열쇠를 챙긴다. 시계에 Q로 소리를 주입하면 3초 뒤 재생된다.
5. 오른쪽의 식당 문을 열고 확장 공간의 받침대 위 인장을 F로 챙긴다. 갑옷과 문도 소리 주입 대상이며 주입 후 3초 뒤 재생된다.
6. 시작 지점 뒤편의 목재 출구 문을 조준하고 F로 탈출한다. 목표물 없이 출구를 사용하면 성공하지 않는다.

## 추가 실험

- 소리를 들고 기다려 자기 위치 폭발·기절·원래 관계 복구를 확인한다. 폭발 자체로 실패하지 않는다.
- [개발 보류·현재 실험 제외] 좌클릭으로 소리를 던진 뒤 즉시 정상 속도로 움직이고 다른 관계를 추출한다. 원래 관계는 투척 시점이 아니라 폭발 시점에 복구된다.
- 첫 대상의 주입 대기 또는 출력 중 다른 대상에서 추출·주입한다. 여러 대상의 출력은 가능하고 이미 대기·출력 중인 같은 대상에 대한 주입은 거절된다.
- 경비 표시는 수면 `zzz`, 인식 추적 `!!`, 고정 위치 확인 `!`, 경계 `?`, 기절 `×`, 회복 후 `패닉 · 면역`이다. 경비와 접촉하면 의뢰가 즉시 처음부터 시작된다.

## 현재 범위

구매한 저폴리 에셋 및 CC0 시계·갑옷·러그를 적용한 개발 중인 3D 씬이다. 건축과 가구·경비 복장을 에셋으로 교체했고, 문·시계·금속 물건과 경비 발소리는 실제 효과음을 사용한다. 미지정 관계만 임시 합성음을 쓴다. 미술 기준과 출처는 stage1-environment-art.md 및 stage1-asset-sources.md에 기록한다. 손·시전 애니메이션, 후속 의뢰와 저장 매개체는 후속 작업이며 투척은 개발 보류다. 구조 벽과 닫힌 문은 가청 범위를 줄이고 시야·폭발 기절을 차단한다. 순간음은 위치까지 확인하고 지속음은 청각을 잃으면 멈춘다. 수면 중 시야는 비활성이라는 임시 설계를 적용한다.

자동 검사: Unity Test Runner에서 PlayMode의 `SoundThief.Tests`를 실행한다. 공통 기반 검증은 `framework-verification.md`, 투척 비활성화 검증은 `sound-ai-decisions.md`, 기존 저택 검증 이력은 `verification.md`에 기록한다.


## 소리로 기회를 만드는 현재 저택

- 서재 경비는 깨어서 세 지점을 순찰한다. 발소리와 이동을 관찰하고 진입 시점을 고른다. 중앙의 높은 책장이 양쪽 통로를 나눈다.
- 시계와 남쪽 황동 물병은 서로 다른 유인 위치다. 주입 후 3초 동안 엄폐로 이동할 수 있다. 시계에서 원래 들리던 틱 소리는 그 관계를 추출하면 사라진다.
- 문·시계·물병에 주입해도 원래 훔친 관계의 음색이 유지된다. 이미 출력 중인 대상에 겹쳐 주입할 수는 없다.
- 인장을 그냥 집으면 금속 소리가 난다. 먼저 그 관계를 추출하면 조용히 집을 수 있지만 느린 운반과 다음 주입 위치를 생각해야 한다. 인장 옆 물병과 문도 주입 대상이다.
- 정문과 식당 앞·뒷문은 연 뒤 8초를 기준으로 닫히고, 사람이 문 가까이에 있으면 닫힘을 미룬다. 무음이면 닫힐 때도 조용하다. 문을 영구히 열어 둔 귀환을 전제하지 않는다.
- 현재 저택 보유 시간은 1/2/3등급 30/24/12초다. 다른 스테이지는 전용 설정으로 조절한다. 투척은 계속 비활성이다.

하나의 지정된 주입 순서를 의뢰 완료 조건으로 검사하지 않는다. 경비를 어디로 움직일지, 손을 언제 비울지, 어느 문으로 돌아올지 선택한다. 자동 경로 검증과 첫 사용자 완주·체감 난이도 평가는 구분한다.


## 현재 강조와 시야 표시

청록색 테두리는 소리 관계/주입이 있는 사물이다. 조준하면 밝은 황금색, 대기·출력 중에는 주황색, 원래 관계가 무음이면 흐린 청록색으로 표시한다. 10m 이내에서 보이며 벽 뒤를 투시하지 않는다. 여행 상자·복도 탁자·문서함·배식장·식기 더미도 사용해 볼 수 있다.

빨간 바닥 부채꼴은 깨어 있는 경비의 현재 시야다. 벽·책장·닫힌 문에 막히는 구간을 반영한다. 잠든 경비는 시야를 사용하지 않으므로 표시하지 않는다. 소리의 예상 도달 범위나 다음 경비 위치를 표시하는 기능은 아니다.


소리를 들고 있어도 자동으로 앉지 않는다. 서 있는 채로 느리게 이동하며 인장을 집을 수 있고, Ctrl을 눌러 직접 앉을 수 있다. 머리 위가 막히면 Ctrl을 놓아도 일어서지 않는다.
