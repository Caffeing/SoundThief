# 경비 자세·가시성·가구 통과 수정

2026-10-30 · ManorPrototype

- 원인은 대기 클립의 뒷짐 자세와, 가구를 다른 하이어라키로 옮긴 뒤에도 NavMeshSurface가 Children만 수집하던 설정이다.
- GuardAppearance의 선택 설정 relaxedArms를 저택 경비 세 명에게 적용했다. 애니메이션 이후 팔 방향을 보정해 양팔을 옆으로 내리고 실제 이동 시 작게 흔든다. 루트 모션은 끄고 NavMeshAgent가 이동을 담당한다.
- 린넨·버건디 의복과 금속의 기본 색을 밝게 조정했다. 상시 외곽선이나 벽 너머 표시는 추가하지 않았다.
- 가구 21개의 충돌을 정리하고, 없던 충돌체 2개 및 나머지 19개의 간단한 박스 형태를 적용했다. 낮은 가구도 넘어가지 않도록 25개 영역에 이동 불가 NavMeshModifierVolume을 지정했다. 별도 하이어라키 객체는 만들지 않았다.
- 기존 Surface 하나와 agent type 0, PhysicsColliders, layer 8을 유지하되 수집을 All로 변경했다. 문 장애물 3개는 기존 carving 방식이고 링크는 없다. 새 이동망은 ManorFurnitureSafeNavMesh.asset이다. 재생성 시 문짝 충돌체를 잠깐 수집에서 제외하고 복구한다.
- 실행 프레임 1353→1809, 게임 시간 27.05→36.01초 진행과 순찰 상태, 팔 자세를 확인했다. Images/stage1-guard-readable.png는 이 실행에서 촬영했다.
- 최종 짧은 경로 확인: 서재 가구 우회 경로 완료, 10개 모서리, 반지름 0.28m 캡슐 검사에서 교차 가구 0개. 순찰 세 구간 모두 PathComplete. 씬 연결 검사 오류 0. 전체 완주 검사는 반복하지 않았다.

앞으로 가구를 다른 폴더로 옮겨도 수집 대상에서 빠지지 않게 유지한다. 새 고정 가구를 추가하면 충돌과 이동 불가 영역을 지정한 뒤 이동망을 재생성한다.
