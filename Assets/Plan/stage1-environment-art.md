# 1스테이지 환경 아트 교체 기획

2026-10-29 · 대상: ManorPrototype · 작업 브랜치: taehyeon

## 목표와 범위

임시 도형으로 남은 건축·시계·갑옷·받침대·인장·러그·출구 표시와 임시 경비 외형을 모델 에셋으로 교체한다. 사용자가 제공한 저택 이미지에 맞춰 푸른 회색 석벽·어두운 목재·버건디 천·탁한 철/황동과 호박색 촛불로 통일한다. 게임의 길드·연습장 제작은 다른 팀원 범위다. 저택의 열쇠 선행 동선, 소리 관계와 주입 3초 지연, 투척 보류를 유지한다.

## 조사한 기법과 이번 적용

아래 적용 기준은 자료를 저택 잠입 게임에 맞춰 해석한 설계다. 보편적인 정답이나 원문에서 제시한 수치로 취급하지 않는다.

| 기법 | 근거 | 이번 적용 기준 |
| --- | --- | --- |
| 모듈 규격과 반복 조립 | Joel Burgess·Nate Purkeypile의 [Skyrim 제작 사례](https://www.gamedeveloper.com/design/skyrim-s-modular-approach-to-level-design) | 벽을 약 3~4m 모듈로 반복하고 길이·모서리·문틀을 맞춘다. 가구를 방 길이만큼 늘리지 않는다 |
| 반복 건축과 고유 소품 구분 | 같은 사례의 반복 피로도 논의 | 건축 규격은 반복하되 책·식기 배치를 통째로 복사하지 않는다. 방의 기능을 소품으로 구별한다 |
| 기능에 따른 에셋 조립 | Unity의 [Kitbashing 제작 사례](https://unity.com/blog/games/realizing-rapid-conceptual-design-with-kitbashing) | 기존 게임 구조 위에 모델을 조립한다. 공통 상호작용 루트와 모델 자식을 분리하고 아트 교체 시 문 힌지·목표 ID를 보존한다 |
| 배치와 조명을 함께 조정 | 위 Unity 사례의 조명 반복 과정 | 책상/열쇠, 인장 전시대, 시계·갑옷에 시선이 닿게 조명을 두고 실제 플레이 시점에서 조정한다. 광원은 랜턴·촛대 위치에 연결한다 |
| 크기·밀도 계층 | 이번 씬 분석에 따른 자체 기준 | 벽/책장/식탁의 큰 형태 → 주입 대상/전시대 → 책/식기의 순서로 확인한다. 이동 구간은 비우고 사용 중인 표면에 소품을 모은다 |
| 제한된 재질과 방별 생활 흔적 | 위 자료를 바탕으로 한 자체 기준 | 4개 재질군을 공유한다. 서재는 읽던 책·수납, 식당은 식기·의자, 홀은 보관/전시로 묶고 무작위 소품 산포를 피한다 |

## 교체와 검증 절차

1. 원본 씬을 보관하고 실제 표시되는 기본 메시·재질을 전수 조사한다.
2. 모델의 크기·원점·앞 방향·재질·라이선스를 확인한다. 텍스처가 빠진 흰 모델을 완료로 보지 않는다.
3. 건축 외형 → 주입 대상/인장 → 경비 복장 → 소품/조명 순으로 교체하고 기능 참조를 보존한다.
4. 보이는 기본 도형이 남았는지 다시 조사한다. 충돌 전용 도형과 경비 상태 글자는 표시용 임시 모델과 구분한다.
5. 실제 프레임이 진행되는 상태에서 현관·홀·서재·식당을 촬영하고, 관통·공중 배치·문 앞 막힘·핵심 대상 가림을 수정한다.
6. 문 개폐·주입 대기·아이템 선택/획득·경비 이동과 기존 의뢰 완주 검사를 수행한다. 실제 검사 결과는 작업 후 기록한다.

원본 점검과 비교 화면은 Logs/AssetAudit, 팀 공유용 출처와 최종 결과는 stage1-asset-sources.md 및 본 문서에 정리한다.

## 추가 요청: 책장 반복과 빈 공간 (2026-10-29)

기존 곡선 책장 8개를 곡선형 2개와 직사각 수납장·낮은 장·좁은 벽 선반·넓은 개방 선반으로 교체한다. 반복 책 묶음은 숨기고, 각 모델의 실제 선반 윗면을 확인해 서로 다른 책 묶음·눕힌 책을 놓는다. 서재에는 사다리·문서 보관함·책상 의자를 더해 사용하는 공간으로 만든다.

현관에는 천을 덮은 대기 벤치와 여행 상자, 홀 가장자리에는 벤치와 독서용 작은 탁자, 뒤쪽에는 린넨 보관함, 식당에는 배식용 수납장·겹친 접시·컵·도기·병을 묶는다. 중앙 러그 세 장은 하나의 긴 러너로 정리한다. 문·열쇠·인장 앞과 중앙 이동로는 비워 둔다. 수납 높이가 달라진 구역은 이전의 큰 가림 충돌을 해제하고 실제 새 모델의 충돌을 적용해 경비 이동망을 다시 굽는다.

## 사용자 이미지에 따른 미술 기준

참고 이미지: `Images/stage1-mood-reference-1.png`부터 `-3.png`. 사진의 파란 석벽과 따뜻한 빛, 굵은 목재 보, 붉은 직물과 사용 흔적을 미술 기준으로 삼는다. 사진에 보이는 손·동전·물약 UI는 이번 기능 요구로 해석하지 않는다.

- 벽: Slavica의 실제 석재 모델을 모듈로 삼아 24개 벽 구간에 5,440개 돌을 엇갈려 조립하고 세 가지 청회색 재질로 묶었다. 서재 입구 두 곳에는 석조 아치를 배치했다.
- 바닥·천장: Cute Dungeon 석재 판과 목재 보를 사용한다. 천장은 원래 바닥 판재를 뒤집었을 때 생긴 표시 문제를 피하도록 목재 보 조립으로 교체했다. 다른 씬의 렌더 설정은 변경하지 않는다.
- 조명: 차가운 실내 간접광 위에 식탁 촛불과 벽·기둥의 랜턴 조명을 배치한다. 랜턴 유리 면에 황금색 발광 재질을 별도로 적용하고, 저택 전용 Volume에서 약한 bloom·대비·비네트를 사용한다.
- 인물: Slavica 인물에 버건디 조끼·린넨 셔츠·가죽 신발과 Quaternius의 열린 투구·견갑을 조합한다. 얼굴이 보이는 저택 경비로 구성하고 기존 대기·걷기를 유지한다. 주입용 장식 갑옷은 별도의 닫힌 투구 모델이다.
- 기능: 외형 자식과 게임 기능 루트를 분리한다. 새 가구의 실제 충돌에 맞춰 `ManorFurnishedNavMesh.asset`을 굽고, 문 개방 구간은 이동 가능하게 유지한다.

## 검증 기록

가구와 경비 복장 교체·이동망 갱신 후 전체 PlayMode 검사 **27/27 통과(120.99초)**. 경비 활성 탈출, 두 열쇠 선행 조건, 문 개폐, 문 주입 3초 지연과 경비 이동 애니메이션을 포함한다. 결과: `stage1-environment-test-results.json`. 이후 천장·조명·랜턴의 시각 전용 마감은 실제 실행 화면에서 확인하며 충돌과 게임 규칙을 변경하지 않는다.

현재 미구현인 벽·문에 따른 청각 감쇠 및 순간음/지속음의 경비 행동 분리는 이번 미술 교체 결과에 포함하지 않는다. 수동 첫 완주와 미술에 대한 사용자 체감 평가는 별도다.


최종 실행 화면에서 프레임 **1817 → 2376** 진행을 확인했다. 새 실행 오류·경고 0건. 최종 저장 씬은 보이는 기본 도형 0개·누락 재질 0개이며 편집 모드로 돌아왔다. 증빙: `stage1-art-verification.json`.

실제 Game 화면: `Images/stage1-art-runtime-hall-hud.png`. 방별 화면은 플레이 중 눈높이에 둔 확인용 카메라에서 촬영했으며 HUD를 포함하지 않는다.
