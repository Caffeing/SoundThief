# 스테이지 공통 구현 기준

- 소리 전달 알고리즘은 스테이지 2의 방·통로 연결 그래프를 기준으로 한다. 공통 구현은 `RoomSoundPropagation`, 기존 스테이지 2의 `JinHoSoundPropagation`은 씬 연결 보존용 파생 컴포넌트다.
- 실제 가청 판정, 플레이어가 듣는 음량, 스캔 전파는 같은 정책을 사용한다. 자기 발소리는 직접 들리는 로컬 음원이다.
- 방 내부 거리, 통로 우회 거리, 닫힌 경계의 추가 비용 및 감쇠를 사용한다. 현재 알고리즘은 직선 기본 가청 반경도 상한으로 유지한다. 실제 파동이 통로를 꺾어 애니메이션되는 전파 시뮬레이션은 아니다.
- 스테이지 1에는 현관·홀·서재·식당·두 벽감과 후면의 구역 및 문 연결을 작성한다. 새 스테이지는 자기 맵에 맞는 구역과 통로를 작성해야 한다. 방 구역을 다른 맵에서 그대로 복사하지 않는다.
- 이동·능력 지속 시간·주입·경비 기본 시야와 이동 속도·기절·경계 시간 등 공통 SoundRules는 스테이지 1을 기준으로 한다. 주입 후 재생 지연은 3초다.
- 스테이지별 지도·의뢰·퍼즐·경비 배치와 순찰 경로는 개별 콘텐츠로 유지한다.
- 기존 `Restore Original Lure Settings` 도구는 예전 스테이지 2 규칙 복원용이며 공통 기준을 다시 덮어쓸 수 있으므로 현재 공통 설정 작업에 사용하지 않는다.

## 이번 적용 범위

1·2스테이지는 같은 공통 소리 알고리즘을 사용한다. 길드·프레임워크 예제·우편 스테이지 등 나머지 맵은 공통 SoundRules와 주입 지연을 맞췄지만 음향 구역 그래프는 아직 작성하지 않았다. 해당 맵은 그래프 작성 전까지 기존 전달 방식을 사용한다.

경로 알고리즘 기존 회귀 테스트 10개 통과. 이번 변경 후 실행 파일은 다시 빌드하지 않았다.

1스테이지 PlayMode 통합 테스트는 테스트 초기 씬에서 완료되지 않아 중단했다. 이 실행을 통과로 계산하지 않는다. 컴파일 오류는 없고 경로 계산 EditMode 테스트 10개는 통과했다. 실제 문 개폐·유인 체감 확인은 남아 있다.
