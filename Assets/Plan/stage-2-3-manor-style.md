# 스테이지 2·3 저택 스타일 통일

스테이지 1의 실제 메시와 재질을 읽어 두 씬의 블록 외형을 교체했다. 기존 씬과 컴포넌트를 재생성하거나 게임플레이 스크립트를 변경하지 않는다.

- 공통: 따뜻한 석벽 모듈, 석판 바닥, 목재 천장과 보, 실제 목제 문, 고정 문틀, 금속 자물쇠, 목제 가구와 호박색 랜턴.
- 스테이지 2: 블록 외형 64개(벽 구간 36개·문 4개 포함)를 교체했다. 기존 열쇠/공명체/휘장 외형과 경비, 거울 표면·테두리·파괴 연출은 유지한다. 관찰 틈의 얇은 벽 조각도 기존 크기 안에서만 외형을 맞춘다.
- 스테이지 3: 블록 외형 127개(벽 구간 16개·문 2개 포함)를 교체했다. 우편 분류소의 작업대·우편 선반·받침·소포를 목재/양피지 스타일로 정리하고, 네 후보 편지에 같은 종이·접힘·봉인 스타일을 적용했다. 안쪽 하역문 외형은 원래 게이트와 함께 올라가며 문틀은 고정된다.
- 기존 렌더러는 숨기고 자식 메시로 외형을 추가한다. 문/편지/아이템의 기존 F 대상과 충돌체는 유지하며 추가 장식에 충돌체를 만들지 않는다.
- 위치·회전·크기, 기존 물리/내비게이션 컴포넌트와 MonoBehaviour 직렬화 설정은 적용 전 백업과 정적으로 비교해 동일함을 확인했다. NavMesh를 다시 굽지 않았다.
- 스테이지 2의 유인/거울 규칙과 스테이지 3의 편지/하역문/길드 귀환 정책은 변경하지 않는다.
- 스테이지 1은 읽기 전용 참고로 사용했다. 작업 중 별도로 들어온 스테이지 1·공통 코드·에셋 복구 변경은 되돌리지 않았다.
- 편집 메뉴: Sound Thief/Apply Manor Style To Stages 2 And 3. 재실행하면 [Manor style] 아래 생성 외형을 다시 만들므로 해당 자식의 수동 수정은 사라질 수 있다. 기존 기능 오브젝트는 유지한다.
- 백업·변경 수·정적 보존 기록·컴파일 결과: Artifacts/StageArtUnification.
- 검증 범위: 컴파일만. Play Mode·실제 이동·문 개폐·거울·편지 읽기·시각적 실행 검증은 하지 않았다. 커밋하지 않았다.
