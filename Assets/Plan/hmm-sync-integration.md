# HMM 동기화와 푸시 통합 기록

원격 `5a7dfc11`, `28256ad6`와 로컬의 에셋 이동·복구 작업을 통합했다.

- 원격 스테이지 2·3 외형은 현재 씬에 선택적으로 복구했다. 현재 게임플레이 컴포넌트와 충돌체 데이터는 유지했다.
- 원격 StageManorVisuals 도구와 우편 재질을 현재 폴더로 옮겨 경로를 갱신했다.
- 원격 위키·기획 문서·외형 적용 기록을 보존했다.
- 원격에서 대량 변경된 에셋 importer/GUID 설정은 그대로 덮어쓰지 않았다. 이번 작업에서 복구·검증한 메타파일 및 재질·충돌 설정을 기준으로 한다. 사용하지 않는 외부 팩 미리보기 씬도 현재 정리본을 유지한다.
- 원본 아카이브·추출본·빌드·로그·개인 구매 다운로드 주소는 커밋하지 않는다.

통합 트리는 위 기준으로 먼저 작성했다. 원격 커밋의 조상을 유지하기 위한 merge는 이 검토된 트리를 유지한다. 강제 푸시는 사용하지 않는다.

최종 코드 컴파일 검사는 오류 0으로 완료했다. 외부 파티클 팩에 기존 멤버 숨김 경고 CS0108이 에디터 로그에 남아 있다. 최신 장식·폴더 변경 전체의 Windows 재빌드는 하지 않았다.
