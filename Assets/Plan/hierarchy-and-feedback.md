# 하이어라키와 상황별 안내 정리

2026-10-30 · ManorPrototype · 사용자 요청: 한국어 이름, 상시 강조 제거, 짧은 검증

## 씬 구성

- 00 게임 시스템: 의뢰와 소리 관리, 게임 화면, 입력 이벤트
- 01 플레이어: 1인칭 카메라
- 02 경비와 순찰: 중앙 홀 경비, 서재 순찰 경비, 식당 경비, 순찰 경로
- 03 저택 구조: 공간별 구조·충돌 기반과 기존 이동망
- 04 상호작용 사물: 현관·중앙 홀과 복도·서재·식당의 소리 사물과 목표물
- 05 환경 장식: 건축 마감, 생활 가구·소품, 소리 사물 주변 가구
- 06 조명과 분위기: 달빛, 공간별 조명과 색감

직접 편집하는 객체 1,951개의 이름을 한국어로 바꾸고 중복된 형제 객체에는 번호를 붙였다. 에셋 내부의 애니메이션 뼈대·메시 경로는 원래 연결을 보존한다. 이름 변경표는 manor-hierarchy-names.json에 저장했다. 편집 도구와 기존 검사의 객체 이름 참조도 함께 갱신했다. 위치·회전·크기를 유지하며 부모만 정리했고 기존 이동망을 재사용한다.

## 안내 방식

소리 사물은 평소에 강조하지 않는다. 상호작용 거리에서 직접 조준한 사물 하나에만 얇고 반투명한 황동색 테두리를 0.15초에 걸쳐 표시하고, 시선을 떼면 사라진다. 무음·주입 상태는 기존 상호작용 안내와 실제 소리 반응으로 읽는다. 파란색 테두리와 평상시 연결선은 제거하고, 추출·주입에 성공한 직후에만 0.3초 연결 효과를 사용한다.

경비 시야는 상시 표시하지 않는다. 10m 이내에서 벽에 가리지 않은 활동 중 경비를 약 0.4초 동안 직접 바라보면, 현재 시야가 바닥에 옅은 적갈색으로 1.4초 동안 나타나고 사라진다. 계속 바라봐도 상시 표시로 이어지지 않는다. 시선을 0.25초 이상 뗐다가 다시 관찰하면 재확인할 수 있다. 벽·가구·닫힌 문 차폐와 수면·기절·패닉 시 숨김을 유지한다. 실제 감지 판정은 바꾸지 않는다.

## 검증 범위

사용자 요청에 따라 긴 38개 전체 검사와 완주 재검사를 반복하지 않는다. 씬 참조·이동망 연결 확인과 조준 시 테두리/평상시 숨김, 관찰 시 시야/자동 소멸/벽 차폐를 확인하는 관련 PlayMode 검사 한 개만 실행한다. 기존 전체 검사 결과는 변경 이전 이력이며 이번 결과와 구분한다.

검증 결과: 관련 PlayMode 1/1 통과(5.71초), 씬 연결 검사 오류 0. 원본은 hierarchy-feedback-test-results.json. 앞으로도 작은 변경은 관련 검사만 실행하고, 전체 회귀 검사는 공통 규칙·이동·진행을 넓게 바꿀 때만 수행한다.


## 가구와 책을 함께 편집하는 묶음

책장·수납장·책상을 16개 가구 단위 묶음으로 정리했다. 각 묶음은 01 가구 본체와 02 선반과 상판의 책으로 나누며, 흩어진 책 묶음 44개를 해당 가구로 이동했다. 홀의 두 수납장은 책이 하나의 통합 메시이므로 홀 수납장과 도서 묶음 안에서 본체와 책을 구분한다. 비표시된 이전 책 배치는 99 보관용 제작 원본으로 옮겼다. 부모 변경 전후 월드 위치·회전·크기 변화 0, 표시 렌더러 집합 동일, 씬 연결 오류 0을 확인했다. 이번에는 실행 검사나 완주 검사를 반복하지 않았다.


사용자 정정 반영: 02 선반과 상판의 책(홀은 02 선반의 책)은 형제 폴더가 아니라 01 가구 본체의 자식으로 배치한다. 부모 변경 시 월드 배치는 유지한다.


## 최종 간소화

중복된 묶음·01 가구 본체·02 책 폴더를 없앴다. 실제 가구 객체 바로 아래에 가구 외형과 책 에셋을 둔다. 책 하나를 감싸던 별도 빈 객체도 제거했다. 가구별 묶음 상위 폴더도 제거해 공간 아래에서 가구를 바로 찾는다. 홀 수납장은 두 본체에 걸친 통합 책 메시가 있으므로 하나의 홀 수납장 객체에 함께 둔다. 위치·회전·크기, 표시 렌더러와 씬 연결을 유지한다. 앞의 세부 폴더 구조는 개발 이력이며 현재 구조는 이 절을 따른다.
