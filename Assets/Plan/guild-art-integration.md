# 길드 중세풍 에셋 통합

- 대상: `Assets/Scenes/Guild.unity`
- 원본: 사용자 제공 `DUNGEON EXPORT/Unity Pack/Dungeon Megapack.unitypackage` (RG Poly, CC0).
- 원본 던전 씬의 반복 석재 바닥·벽·기둥, 벽면 횃불, 가구 구획 방식을 현재 길드 동선에 맞춰 재구성했다. 던전의 통로 전체를 길드에 그대로 대체하지 않았다.
- 석재 포장/벽체, 목재 천장과 보, 의뢰 데스크와 장부/촛대, 휴게 테이블/좌석, 보관장/상자/술통, 깃발과 따뜻한 벽 조명을 추가했다.
- 기존 의뢰 테이블과 문서 넘김, 의뢰 수락/완료/재수락 정책, 출발 문과 길드 복귀 위치, 연습장의 기능 오브젝트와 가림벽을 유지했다.
- 기존 바닥/벽/테이블의 콜라이더는 유지하고 외형 렌더러를 대체했다. 장식은 Ignore Raycast 레이어로 F 상호작용을 가리지 않으며, 휴게 가구에는 단순 콜라이더를 별도로 두었다.
- 연습장 NavMesh는 변경하거나 재생성하지 않았다. 새 가구는 로비의 가장자리 구역에 배치했다.
- 새 장식 루트: `Guild art — Dungeon Megapack`. Editor 도구: `Sound Thief/Apply Medieval Guild Art` (현재 배치를 다시 생성하므로 수동 수정 후 재실행 시 주의).
- 기존에 있던 ThirdParty 하위 에셋은 재사용하고, 추가 에셋은 `Assets/Dungeon Megapack`에 가져왔다. 원본 예제 씬은 참고용이며 빌드 목록에 추가하지 않았다. 패키지 동봉 전역 렌더링 설정 변경은 복원했다.
- 검증 범위: Unity 스크립트 컴파일 통과(오류 0). Play Mode, 이동/상호작용/그래픽 실행 검증, 테스트는 수행하지 않았다. 가져오기 중 Blender 미설치 메시지 1건이 기록됐으나 최종 C# 컴파일 실패는 없으며 배치에는 FBX 프리팹을 사용했다.
- 원본 길드 백업 및 컴파일 기록: `Artifacts/GuildArtIntegration`.
- 커밋하지 않았다.

## 2층 및 시설 확장

- 중앙 홀 상부를 개방한 U자형 2층 회랑과 실제 바닥, 오른쪽 계단, 연속 충돌체가 있는 난간을 추가했다. 기존 천장과 보를 높이고 2층 석재 외벽을 이어 붙였다.
- 계단 구간의 2층 바닥은 비워 두었다. 계단 높이는 층 높이에 연결하며, 원래 오른쪽 휴게 가구와 콜라이더를 함께 왼쪽으로 옮겨 접근로를 확보했다.
- 자료실/독서 공간: 벽면 책 선반, 장부, 독서 책상과 좌석.
- 모험가 숙소: 침대, 이불/베개, 개인 보관함, 가림막.
- 전략 회의 공간: 대형 회의 테이블, 의자, 지도와 지도 표식.
- 길드장 집무 공간: 집무 책상, 의자, 회계 장부와 촛대.
- 치료/연금술 공간: 치료 침대, 약제 작업대와 약병, 가림막.
- 1층 장비 작업 공간: 장비 작업대, 검/방패 전시, 보관 상자.
- 시설은 이동 가능한 공간과 소품으로 구성했다. 새로운 제작/치료/상점/숙박 상호작용 로직은 추가하지 않았다.
- 기존 의뢰 테이블/문서 UI/수락 정책/출발 문/길드 복귀 지점, 연습장 기능 오브젝트와 경비 NavMesh는 유지했다. 2층은 플레이어용이며 NPC 이동 경로는 추가하지 않았다.
- 독립 편집 메뉴: `Sound Thief/Apply Guild Second Floor and Facilities`. 기본 중세풍 길드 생성 메뉴에서도 2층 배치를 함께 생성하도록 연결했다.
- 검증: 새 Editor 코드 컴파일 통과(오류 0), 씬 저장 완료. Play Mode나 실제 계단 이동/시설 동선/렌더링 검증은 하지 않았다. 커밋하지 않았다.
- 확장 전 백업: `Artifacts/GuildArtIntegration/Guild.before-second-floor.unity`.
