# 길드 의뢰 테이블과 성공 복귀 — 2026-10-29

## 실행 흐름

길드의 기존 테이블을 F로 조준·상호작용 → 한 의뢰와 간략한 설명을 문서로 열람 → 좌우 방향키로 종이 넘김 → F/Enter로 현재 의뢰 수락 → ESC로 닫기 → 선택형 연습 또는 출구 직행 → 문 F로 저택 진입 → 인장 절도 후 출구 F로 성공 → 자동 길드 복귀.

열람 중 이동·마우스 시점·능력·R 재시작을 차단한다. 수락해도 열람을 유지하며 씬을 바꾸지 않는다. ESC는 열람만 닫는다. 테이블 밖 ESC 일시정지와 스테이지 Tab 의뢰창은 유지한다. 문서 열람은 게임 시간을 멈추지 않으며 보유 시간 초과 기절 때는 열람도 닫힌다.

## 데이터와 연출

- `GuildContractTable`: 문서 목록, 선택/수락 인덱스, 열람 상태, 중복 넘김·수락 차단. 앞뒤 문서를 순환하며 문서 한 장일 때의 이동과 전환 중 수락을 막는다. ESC 취소 시 확정 선택을 유지한다.
- `GuildContractOffer`: StageDefinition·씬 경로·available 설정. 실제 수행 가능 의뢰는 푸른 저택의 인장 하나다. 나머지 두 문서는 넘김 확인용 준비 중 예시이며 수락·이동하지 않는다.
- `GuildContractView`: 한 의뢰의 본문과 간략한 설명을 uGUI/TMP로 표시한다. 선택 의뢰와 현재 수락 의뢰는 분리한다. 준비 중·수락 가능·수락 완료를 텍스트로 구별한다.
- `ContractPageCurl`: CanvasRenderer를 갖는 절차적 종이 메시. 책장처럼 회전하지 않고 작은 휨만 사용한다. ←는 앞 문서를 왼쪽으로 빼 뒤에 넣고, →는 뒤 문서를 같은 옆 공간으로 꺼내 앞에 덮는다. 종이가 묶음 밖으로 완전히 빠진 시점에만 겹침 순서를 바꾸고 전체 본문이 종이를 따라 이동한다. 부드러운 가감속·기울기·그림자로 안착을 표현한다. 새 이미지·텍스처·외부 미술 에셋은 사용하지 않는다. 종이 블록 세 장과 인쇄선은 기존 테이블 위에 놓았다.
- `ThiefPlayer.FindTarget`: 아래를 볼 때 자신의 CharacterController가 조준을 가로막지 않도록 자기 충돌체만 제외한다. 가장 가까운 다른 물체와 벽은 계속 차폐한다.

기존 게시판과 게시판 문구는 비활성화하고 기존 테이블 오브젝트에 상호작용을 연결했다. 기존 길드 Transform의 위치·회전·크기는 변경하지 않았으며 문서 묶음·종이/선·복귀 지점 20개 Transform을 추가했다. 연습장·공통 스테이지와 투척 비활성 정책은 유지했다.

## 성공과 실패

저택 MissionDirector의 returnToGuildOnSuccess를 켜고 Guild 씬 경로를 지정했다. 성공 안내 후 자동 복귀하며 Guild return spawn은 출입문 안쪽(-2, 0.05, 20.25), 실내 방향이다. 초기 길드 시작 위치는 유지한다. 복귀 플래그는 목적지 경로에 한정하여 한 번 소비한다.

완료한 의뢰 수락·아이템·보유 소리·기절·문서 열람·일시정지를 이월하지 않는다. 현재 의뢰를 다시 수락해 반복할 수 있고 영구 완료·보상/저장은 추가하지 않았다. 접촉 실패는 수락을 유지한 채 해당 스테이지 전체 재시작이다. 공통 예제 스테이지의 기존 완료/재시작은 자동 귀환 설정을 켜지 않아 유지한다.

## 문서 이동 수정·최신 검증 (2026-10-29)

- ←: 현재 앞 문서 전체를 왼쪽 옆으로 빼고 묶음 뒤로 넣는다. →: 맨 뒤 문서를 같은 옆 공간으로 꺼내 앞으로 가져와 덮는다. 책장 회전·뒤집기를 사용하지 않는다.
- 종이가 완전히 옆으로 나온 중간 지점에서만 앞뒤 그리기 순서를 바꾼다. 제목·본문·목표·수락 상태가 종이를 따라 유지된다.
- 이동을 위한 옆 공간을 확보하고 작은 휨·기울기·들어올림·그림자와 부드러운 가감속을 적용했다. 설명 문서는 빈 화면으로 사라지지 않고 새 문서가 안착하는 시점에 내용이 바뀐다.
- 문서 묶음은 순환한다. 시작 문서에서 ←는 다음 앞면으로, →는 마지막 문서를 앞으로 가져온다. 한 장일 때 이동하지 않는다. 수락·ESC 취소·이동 잠금은 유지한다.

## 종이 전환 깜빡임 수정 (2026-10-29)
