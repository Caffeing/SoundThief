## 발견한 실행 차단 및 통합 오류

| 문제 | 원인과 조치 |
| --- | --- |
| 컴파일 실패 | 길드가 사용하는 `MissionDirector.isGuild/practice`, 플레이어/월드 초기화 API가 공통 기반 교체 과정에서 사라졌다. 공통 StageDefinition·이벤트·아이템 ID 처리를 유지하며 길드용 연결과 초기화를 복구했다. |
| 게시판이 수집물로 처리됨 | 두 브랜치가 enum 값 5를 서로 다르게 사용했다. 공통 Collectible=5는 보존하고 길드 게시판=6, 출구=7, 초기화=8을 명시했다. 기존 길드 씬의 해당 세 오브젝트만 Editor에서 이관했다. enum 값은 재정렬하지 않는다. |
| 길드에서 시작할 수 없음 | 빌드 목록에서 길드가 빠지고 공통 예제가 첫 씬이었다. 길드를 첫 씬으로 등록하고 저택 진입 경로를 연결했다. 예제·템플릿은 유지했다. |
| 수락 전 이동 및 길드 조작 누락 | 길드에서는 수락 전에도 이동/연습 가능하도록 복구했다. 수락은 자동 이동을 일으키지 않으며 출구 F로만 스테이지에 진입한다. 연습 완료는 출발 조건이 아니다. |
| 씬 전환 시 의뢰 상태 유실 | 목적지 경로에 한정하여 수락 상태만 넘긴다. 연습 소리·아이템·학습 기록은 전달하지 않는다. 의뢰 실패/재시작은 해당 스테이지를 새로 로드한다. |
| 연습 초기화 및 안내 불일치 | 연습 상태 기록을 의뢰 목표와 분리했다. 로비 복귀 시 연습 경비·출력·관계를 초기화하며 수락은 유지한다. 길드 HUD 안내와 의뢰창을 복구하고 비활성 투척을 필수 연습으로 표시하지 않도록 했다. |
| 키보드가 없으면 타이머 처리까지 중단 | 입력 장치가 없는 경우에도 게임 시간/소리 만료 처리가 진행되도록 Update의 조기 반환을 수정했다. |
| 테스트와 실제 설정 충돌 | 투척 보존 검사는 테스트 전용 복제 설정에서만 활성화한다. 공유 SoundRules의 throwingEnabled=false는 유지한다. 병합 회귀 검사 3개를 추가했다. |

길드 씬은 원래 배치와 기존 오브젝트 ID를 보존하여 Editor API로 저장했다. 공통 StageInventory 컴포넌트와 새 직렬화 필드가 추가되었다. 씬 생성기로 재생성하지 않았다.
