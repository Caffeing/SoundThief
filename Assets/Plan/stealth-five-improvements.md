# 엄폐·현관 기상·시야·추격·발소리 개선

2026-10-30

책장처럼 높은 가구는 서 있는 플레이어도 가린다. 낮은 책상은 그 뒤에서 앉아 눈높이가 상판 아래로 내려가면 시야를 차단한다. 실제 가구 충돌체로 경비 눈과 플레이어 눈 사이를 검사하며, 앉은 눈높이는 0.72m로 조정했다.

현관 경비는 들을 수 있는 2등급 이상의 소리 한 번에 깨어 조사한다. 현관문을 무음으로 열면 깨지 않는다. 문 소리의 발생 위치는 경첩 바닥 대신 실제 문짝 중심이며, 원래 소리 등급은 유지한다. 다른 경비의 누적 기상 설정은 유지한다.

순찰·조사 기본 속도는 2.2m/s이고 추격 중에는 5.2m/s로 빨라진다. 시야를 놓쳐 마지막 위치를 조사하면 기본 속도로 돌아온다.

플레이어 발소리는 실제 이동 거리에 맞춰 재생한다. 보통 걸음은 1.5m마다 음량 0.42, 앉은 걸음은 0.85m마다 음량 0.12다. 정지·공중·기절·일시 정지에는 재생하지 않는다. 이번 발소리는 플레이어에게 들리는 음향 피드백이며 경비를 자극하는 관계 소리·기상 규칙과는 구별한다.

시야 표시는 0.4초 관찰 후 1.4초만 표시하는 기존 방식에 부드러운 좌우/거리 가장자리, 매 프레임 갱신, 낮은 가구와 현재 눈높이 반영을 적용했다. 바닥 높이 판정은 같은 층의 0.25m 이내로 제한해 책상 위로 시야 메시가 들뜨지 않도록 한다.

실제 서재 집무 책상에 빠져 있던 물리 충돌과 이동 불가 영역을 지정하고 현재 이동망을 재생성했다. 편집기에 남아 있던 변경을 보존한 뒤 진행했다.

경비 추격 애니메이션 속도도 이동 속도에 맞춰 조정했다. 씬에 저장돼 있던 이전 시야 메시 3개를 제거하고 실행 시 새 메시만 생성한다. 책상 충돌에 묻히던 식당 열쇠는 상판 위로 올려 상호작용을 유지했다. 플레이어 발소리는 보유 Kenney Impact Sounds의 footstep_concrete_000.ogg를 사용한다.

검증: 관련 PlayMode 5/5 통과(8.1초). 전체 회귀·완주 검사는 반복하지 않았다. 결과는 stealth-five-test-results.json.


## 운반 중 자동 앉기 해제

인장 소리를 추출해도 자동으로 앉지 않는다. 이동 속도는 운반 속도로 유지하고, Ctrl을 눌렀을 때만 앉는다. 낮은 천장 아래에서는 Ctrl을 놓아도 일어서지 못한다. 서서 느리게 운반할 때 발소리 음량은 0.28, 앉았을 때는 0.12다. 실제 인장을 조준·추출하고 서서 다시 조준해 획득한 뒤 Ctrl로 앉았다 일어나는 경우를 포함해 관련 PlayMode 6/6 통과(11.31초). 결과: standing-carry-test-results.json. 현재 저택의 추격 속도 설정은 3.5m/s이다.
