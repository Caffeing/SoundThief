# 경비 문 통과·발소리와 실제 앉기

2026-10-30

경비 발소리의 기본 음량을 0.45에서 0.9로 높였다. 방향성·거리·벽과 문에 의한 감쇠는 유지한다.

경비는 이동 목적지가 문 반대쪽에 있으면 약 1.6m 앞에서 문을 열고 지나간다. 문 장애물의 이동망 반영을 0.25초 기다린 뒤 원래 목적지로 다시 경로를 잡는다. 경비가 직접 연 문 소리는 본인에게 재유인 자극이 되지 않는다. 자동 닫힘과 통과 중 닫힘 방지는 유지한다. 열쇠 선행 조건을 보존하기 위해 아직 잠긴 문은 열지 않고, 플레이어가 한 번 잠금 해제한 문 또는 원래 잠기지 않은 문을 연다. 씬 재시작 시 잠금 해제 기록은 초기화한다.

앉기는 카메라만 내리는 방식에서 실제 몸 높이를 줄이는 방식으로 변경했다. CharacterController 높이는 1m로 줄고 발바닥 위치는 유지한다. 머리 위가 막히면 일어서지 않고 낮은 자세를 유지하다 공간이 확보되면 일어난다. 눈높이는 0.72m를 유지하며 약 0.12초의 부드러운 전환, 앞쪽으로 7cm 몸 숙임, 시야각 4도 축소, 앉은 걸음의 작은 흔들림으로 자세 변화를 표현한다. 낮은 자세에서는 느린 속도와 작은 발소리를 유지한다. 기본 이동 시에도 실제 이동 거리에 따른 작은 상하 움직임을 적용했다.

검증: 관련 PlayMode 3/3 통과(8.41초). 잠금 유지·발소리 음량, 경비의 재개문 후 실제 문턱 통과, 몸 높이/발 위치/시야각 변화, 낮은 천장 아래 기립 방지와 해제 후 기립을 확인했다. 전체 회귀·완주 검사는 반복하지 않았다. 결과는 guard-doors-crouch-test-results.json이다.
