# Goal 실행 프롬프트 — 팀 공통 스테이지 개발 기반

D:/SoundThief에서 Assets/Plan/framework-development.md에 따라 팀원들이 서로 다른 씬에서 스테이지 1 및 후속 스테이지를 제작할 공통 기반을 완성한다. 사용자 정정에 따라 길드·훈련장 콘텐츠 작업을 중단한다.

플레이어·소리 능력·상호작용·경비·의뢰 진행을 재사용 가능한 공통 프리팹과 런타임으로 정리한다. 특정 저택 이름·아이템명·씬 경로를 데이터로 분리한다. 씬당 StageContext가 연결을 관리하며, StageDefinition에서 임무 설명과 필요한 아이템을 정한다. 서로 다른 아이템 ID와 문 요구 조건을 지원한다. 성공과 실패/재시작의 공통 규칙을 유지하고 연습 여부를 의뢰 조건으로 사용하지 않는다.

새 씬에 기반을 설치하는 에디터 도구, 잘못된 설정을 알려주는 검증 도구, 팀원용 제작 가이드, 별도 설정의 최소 예제를 제공한다. 기존 저택은 회귀 검사 예제로 유지한다. 사용자 수정은 보존하고 새 아트/길드/훈련장/완성 스테이지 콘텐츠/저장/네트워크는 범위에 넣지 않는다. Unity 컴파일·기존 능력 회귀·다른 씬에서 수집/완료/재시작 및 실제 화면을 검증하고 결과를 기록한다.
