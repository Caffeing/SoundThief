# taehyeon 방식 공통 적용 — 2026-10-30

사용자 결정: 길드·의뢰를 제외한 주입, 청각 전달, 소리 조사, 경비, 문·절도, 스테이지는 taehyeon 방식을 수용한다. 원본은 `origin/taehyeon` `9cba1de4a00118738df8a0cdd00b7ee50b92c61e`이며 작업 브랜치는 HMM이다. 커밋·스테이징·푸시는 하지 않았다.

## 적용

- 주입은 taehyeon 원본 SoundEmitter의 공통 3초 지연으로 교체했다. 1차 통합 때 추가했던 지연 설정 필드와 길드 즉시 출력 예외를 제거했다. SoundEmitter.cs와 SoundRules.cs는 원본과 일치한다.
- 연습장도 같은 주입 대기→출력→감쇠→관계 복구를 사용한다. 주입 직후 손이 비고 보통 이동·다음 추출이 가능하다. 대기 중인 대상도 중복 주입을 거부한다.
- 조준만으로 연결선을 상시 표시하던 길드 예외를 제거했다. 추출·주입 때 짧게 연결 효과를 표시하며 능력 안내와 주입 대기 HUD도 taehyeon에 맞췄다.
- 청각은 원래 등급을 유지하면서 거리와 지정 벽·닫힌 문에 따라 가청 범위를 계산한다. 순간음은 발생 위치/도달 가능한 끝까지 조사하고, 지속음은 출력 종료·청각 상실 때 경계한다.
- 서재의 깨어 있는 순찰, 홀·식당의 수면 시작, 시야 추적·마지막 위치 조사·기절 후 패닉, 문 주입·자동 닫힘·통과 보호, 절도 소음과 원음 재생은 이미 가져온 taehyeon 구현을 유지한다.
- 저택 씬·모델·재질·소리·배치는 taehyeon 원본을 사용한다. 위치·회전·크기 1,081개가 일치한다. 통합 중 고친 이동망과 문 물리 동기화는 유지한다.
- 투척은 taehyeon 현재 설정처럼 비활성이다. 길드/저택의 보유 시간 데이터 구분도 원본에 존재하는 구성이므로 유지하며, 별도 즉시 주입 분기는 없다.

## HMM에 남긴 연결

| 파일 | 원본과 다른 이유 |
| --- | --- |
| MissionDirector | 길드 의뢰 수락·출구 출발·접촉 재시작·성공 후 길드 문 복귀 |
| Guild 전용 스크립트와 씬 | 문서 열람·좌우 문서 이동·ESC·선택 연습·초기화. 연습 안내 문장만 지연 출력에 맞춰 갱신 |
| ThiefPlayer / ThiefHud | 길드 문서 입력 잠금·화면, 학습 기록·복귀 위치·초기화, 키보드 부재 처리. 실제 능력 동작은 taehyeon |
| SoundRelation | 기존 씬의 직렬화 값과 길드 상호작용 enum 호환 |
| GuardAgent | 연습장 밖 비활성·연습 초기화·길드 접촉 예외·초기 Goal 보정. 스테이지 AI는 taehyeon |
| SoundWorld / SoundProjectile | 길드 연습 효과 초기화와 월드별 투척물 취소용 연결 |
| ThiefInteractable | 길드 테이블·출구·연습 초기화, 문 회전 직후 Physics 동기화 |

이 차이는 HMM 능력 방식을 별도로 유지하기 위한 분기가 아니다. 길드·의뢰를 보존하고 가져온 시스템이 정상 연결되도록 하는 코드다.

## 검증

- Unity 6000.3.19f1 컴파일 성공. 최종 PlayMode **70/70 통과**, 실패·건너뜀 0, 199.14초.
- 연습장 주입이 즉시 출력되지 않고 지연 후 출력하며 손이 즉시 비는지, 조준 시 상시 연결선이 없고 추출 후 짧게 표시되는지 새 회귀 검사로 확인했다.
- 기존 길드 문서·선택 연습·초기화·출발·성공 후 문 복귀, 소리·AI·아이템·접촉 재시작·일시정지, 실제 경비와 제한 시간을 켠 저택 완주 검사를 함께 통과했다.
- 누락 스크립트·재질·메시·오류 셰이더 및 StageContext 검증 오류 0.
- 길드·의뢰 핵심 7개 파일 해시 보존, 원본 저택 배치 보존, HMM HEAD `22fba57` 유지, 스테이징 없음.
- 물병의 대체 유인 완주 경로는 별도 레벨 검토 항목이다. 기존 테스트의 낡은 동선 가정을 통과시키기 위해 원본의 벽·순찰·시간을 바꾸지 않았다. 물병 주입·출력·복구와 시계 경로 완주를 구분해 검증한다.
- 이전 통합에서 기록한 원본 FBX 면 교차 경고 두 건은 같은 상태다. 컴파일·실행 오류는 없다.
