# 소리 지형 스캔

Unity 6000.3.19f1 / URP 17.3의 Render Graph용 독립 데모다. 화면의 depth로 표면의 월드 좌표를 복원하고 normals와 깊이 차이로 모서리를 강조한다. 월드 높이 간격선과 희미한 표면 격자가 실제 보이는 표면에 붙는다. 소리 중심에서 구형 경계가 확장하고, 표면을 지난 뒤 잔광이 사라진다.

## 데모

`SoundScanDemo.unity`를 열고 플레이한다. V는 소리 발생 위치에서 스캔을 다시 시작한다. 기본적으로 5초마다 자동 재생하며, 데모 제어 오브젝트의 `Repeat Automatically`를 끌 수 있다. WASD로 카메라를 이동하고 Q/E로 높이, 좌우 방향키로 회전한다. 데모의 파이프라인은 플레이 중에만 현재 품질 설정에 임시 적용되며 종료 시 원래 설정으로 복원된다.

## 게임 씬에 연결

1. 대상 카메라가 사용하는 URP Renderer Data에 `SoundScanRendererFeature`를 추가하고 Shader에 `SoundTerrainScan.shader`를 지정한다. 각 품질 단계가 별도의 렌더러를 사용한다면 해당 렌더러마다 설정한다.
2. 대상 카메라에 `SoundScanController`를 추가한다. 이 컴포넌트가 없거나 활성 스캔이 없으면 스캔 패스를 실행하지 않는다.
3. 게임 이벤트에서 해당 카메라의 컨트롤러를 참조하여 `scanner.TriggerSoundScan(position, loudness)`를 호출한다. `loudness`는 0~1로 제한되고 0은 스캔을 생성하지 않는다. 예: `scanner.TriggerSoundScan(doorPosition, 0.7f);`
4. 컨트롤러에서 색상, 밝기, 간격, 선 두께, 모서리 강도, 파면 폭, 속도, 최대 반경, 잔광 초, 동시 개수를 조정한다. 활성 제한은 1~8이며 초과 시 가장 오래된 파동을 교체한다. 각 파동은 시작 시의 반경·속도·잔광 값을 유지한다.

현재 저택 씬은 카메라의 `SoundScanSoundBridge`가 `SoundWorld`의 게임 소리와 플레이어·경비 발소리를 받아 스캔한다. 소리 관계가 무음이면 발생하지 않으며 기본 최대 거리는 경비의 등급별 가청 거리와 같다. 벽·문 감쇠는 16방향과 각 방향의 네 거리를 표본으로 삼는 근사치로 시각화한다. 소리는 거리에 따라 옅어진다. 같은 발생원의 지속 출력은 기본 1.2초 간격으로 제한하지만, 플레이어·경비 발소리는 재생될 때마다 표시한다. 현재 발소리는 청각 자극이 아니므로 경비를 깨우지 않는다. 지속 앰비언스는 연결하지 않는다. PC와 모바일 렌더러에 기능을 설치했으며, 카메라에 컨트롤러가 없으면 실행되지 않는다. 스캔은 게임 시간을 따르므로 일시정지 중에는 멈춘다.

## 범위와 한계

- 화면에서 실제 깊이·노멀 텍스처에 기록된 불투명 표면만 표현한다. 가려진 표면과 깊이에 기록되지 않는 반투명 물체는 표시하지 않는다. 물리적인 소리 차폐·반사·굴절은 계산하지 않는다.
- 선은 월드 높이와 표면 방향에 기초하므로 카메라 이동과 무관하다. 완전히 평평한 바닥은 높이 등고선이 구분되지 않으므로 보조 격자를 사용한다. 노멀맵 세부 표현 여부는 각 머티리얼의 URP DepthNormals 패스 구현에 달려 있다.
- 깊이/노멀 경계 검사는 인접 픽셀 기반이므로 먼 거리나 얇은 물체에서는 계단 현상과 두께 변화가 생길 수 있다. 실제 디바이스와 해상도에 맞춰 간격·굵기·밝기를 조절해야 한다.
- Render Graph가 켜진 URP를 대상으로 한다. 호환성 모드, XR, 카메라 스택, 모바일 성능은 별도 검증이 필요하다. 빌드에 데모를 포함하려면 Build Profiles의 씬 목록에 추가한다.
