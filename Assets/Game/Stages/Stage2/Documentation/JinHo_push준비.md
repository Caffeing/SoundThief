# JinHo push 준비 기록

2026-10-30. 파일 정리는 개발 중인 변경을 공유하기 위한 준비다. 현재 기능이 모두 완성됐다는 뜻은 아니다. 과거 자동 검사 실패·사용자 직접 플레이 확인·미검증 항목을 [요구사항과 검증](JinHo_요구사항과검증.md)에서 구분한다. 사용자는 거울 차폐/유인2 발견 문제가 없다고 후속 확인했으며, 현재 확인된 자기 반사 외형 부재는 PlayerRig에 몸 Renderer가 없는 상태와 관련된다.

## 정리 범위

Git 변경은 공통 스크립트 2개와 JinHo 자산·설명·작업 지침 및 `.gitignore`다. 기준 씬·공유 프리팹/설정·Player/HUD/미션은 이번 정리에서 변경하지 않는다. Git 브랜치 생성·stage·commit·push는 수행하지 않는다.

참조 조사 후 옛 파일/산출물 148개(7,860,698바이트)를 Assets에서 제거하고 로컬 `Temp/JinHoPublishAudit/backup/`에 보존했다. 파일별 경로·해시·크기는 같은 로컬 감사 폴더의 `removed-files.json`에 있다. 이 백업과 원시 실패 기록은 Git에 포함되지 않는다.

- 폐기: B1.3 및 2배 검토 씬 2개와 각 전용 NavMesh, 더 이상 사용하지 않는 유리 재질, 과거 배치 빌더 4개, 과거 배치 전용 Play 테스트 5개.
- 보존: 현재 맵, 작은 기능 검증 씬과 테스트, 현재 맵 테스트, 소리 계산 테스트, 런타임/재질/셰이더/규칙/전용 프로필, 현재 벽 동기화 도구와 작은 검증 빌더.
- 문서: 반복된 조사 로그·폐기 사양·개인 PC 경로를 포함한 문서를 백업하고 Assets/Game/Stages/Stage2/Documentation에 공용 안내·구현 설명·요구사항/검증·이 기록으로 정리했다. 외부 옵시디언 원본은 삭제하거나 변경하지 않았다.
- 재생성 방지: 구형 틈/유리 생성 메서드를 제거하고, 현재 맵 테스트 출력은 Temp/JinHoValidation으로 옮겼다. 옛 ValidationEvidence 경로는 `.gitignore`에 추가해 우발적 재생성도 제외한다.
- 전용 Build Profile: 삭제된 씬/중복을 제거하고 현재 JinHo 씬을 추가했다. 활성 프로필은 바꾸지 않았고 공유 씬 목록은 변경하지 않았다.

## 문서를 함께 올려도 되는가

현재 Assets/Game/Stages/Stage2/Documentation의 네 문서와 `.meta`, 루트 AGENTS.md는 구현 범위·연결·미해결 상태를 전달하는 프로젝트 문서로 함께 올린다. 개인 절대 경로·로컬 스택 추적·중복 대화 로그는 정리했다. 옵시디언 원본 파일이나 제3자 자료를 새로 복사하지 않았다.

사용 여부가 없는 파일과 검증에 필요한 소스는 구분했다. 현재 실패하는 거울/유인2 테스트는 문제를 드러내므로 유지했다. 이 변경은 완성본 배포보다 미해결 상태를 명시한 개발 브랜치 공유에 해당한다.

## 검증 상태

정리 전 현재 씬은 JinHo, Play 정지, 저장 완료였고 Missing Script 0개, StageContext/음향 참조 검사 오류 0개였다. 정리 대상으로 지정한 GUID를 남은 Assets가 참조하지 않는 것을 확인한 뒤 파일을 이동했다. 이후 검증 결과는 실제 확인 후 아래에 덧붙인다. 이번 작업에서는 Play 테스트·빌드·전체 동선을 실행하지 않는다.

정리 후 스크립트 재컴파일은 오류 없이 완료됐다. 현재 JinHo의 Missing Script 0개, StageContext/음향 검사 오류 0개, 씬/프로필 루트의 AssetDatabase 의존 경로 누락 0개를 확인했다. 현재 씬은 Play 정지·미저장 변경 없음이며 유인1 추가2초를 유지한다. 현재 씬과 작은 검증 씬의 의존 경로 집합은 정리 전후 동일했다.

정리 직전 보존 해시와 비교한 136개 파일이 동일했고, 자산에서 실제 수정된 것은 JinHo 전용 프로필뿐이었다. 제거된 씬/이동 데이터/유리 재질 10개 파일은 폐기 대상으로 명시한 파일과 `.meta`다. 현재 맵 배치·런타임·기준 씬·공유 자산·공통 스크립트는 이번 정리에서 바뀌지 않았다.

Git 후보 파일의 자산/메타 짝, Markdown 링크, 파일 크기, 개인 절대 경로와 일반적인 인증키 패턴을 정적으로 조사한다. 이 검사는 알려진 형식을 찾는 점검이며 모든 형태의 민감정보 부재를 보증하는 것은 아니다. 외부 GitHub로 전송하거나 비밀값을 출력하지 않는다. 전체 후보 목록과 해시는 로컬 `Temp/JinHoPublishAudit/audit-final.json`에 있다.

최종 후보는 66개 파일, 약 0.54MB다. 인증키 패턴 일치·개인 절대 경로·깨진 Markdown 링크·자산 메타 누락/고아 메타·50MiB 이상 파일은 모두 0건이었다. `git diff --check`도 통과했다. 기존 실패 시나리오의 수정/재검증, 빌드, 새 브랜치 생성과 push는 이 결과에 포함되지 않는다.
