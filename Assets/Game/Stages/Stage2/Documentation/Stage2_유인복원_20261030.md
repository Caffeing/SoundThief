## 코드 근거와 변경

- `Assets/Game/Runtime/SoundEmitter.cs`: `injectionDelaySeconds=3f` 추가. 시작 시각에 선택한 지연 적용. Stage2만 0. 감쇠/출력은 기존 한 경로를 사용한다.
