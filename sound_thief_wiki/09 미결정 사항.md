# 미결정 사항

## 확정한 주요 규칙

- 의뢰와 스테이지는 1:1이다. 길드는 의뢰 거점이고 연습장으로 기본 학습 일부를 분리한다. 기존 저택은 스테이지 1이며 목표 물건을 훔친 뒤 밖으로 나와야 성공한다. 경비병과 닿는 즉시 실패하며 실패·재시작은 해당 의뢰 전체 초기화다.
- 지정 거리 안에서 상호작용 가능할 때 두 매개체를 시각적으로 연결해 발생 전 소리를 추출할 수 있다. 해당 관계의 모든 상호작용 소리를 제거한다.
- 보유 중 등급 유지·강제 느린 이동·등급별 제한 시간을 적용한다. 사용 후 다음 소리를 추출한다.
- 여러 대상의 주입 출력은 허용하되 같은 대상에서 소리 재생이 겹치지 않게 한다. 주입 대상 파괴는 없다.
- 주입 감쇠 등급 0에서 원래 관계를 복구한다. 사용 시 발생한 소리 위치는 플레이어 이동과 독립적이다.
- 방출은 투척이며 바닥 착지 시 그 자리에서 순간 폭발해 범위 내 AI를 기절시킨다. 기절 범위는 벽을 넘지 않는다.
- 아직 들고 있는 소리의 시간 초과 폭발은 현재 플레이어 위치에서 발생하고 원래 관계를 즉시 복구한다. 소음과 플레이어 기절이 발생하며 폭발 자체로 게임 오버는 아니다. HP는 없다.
- 투척 즉시 느린 이동 해제·재추출 허용. 원래 관계는 폭발 후 복구한다. 투척 후 기존 제한 시간이 계속되고 착지 전 만료 시 공중 투척물 현재 위치에서 폭발한다.
- 기절 중 이동·모든 상호작용 봉인. AI 회복 후 패닉 강제 `?` 동안 모든 자극·기절 공격에도 상태를 고정한다. 패닉 종료 후 기절을 다시 적용한다.
- 소리 확인 이동 중 더 높은 등급의 소리가 나면 새 소리 위치로 목표를 바꾼다. 플레이어 발견은 항상 우선한다.
- `!!`는 플레이어 인식·위치 갱신, `!`는 고정된 위치로 이동, `?`는 현 위치 경계, `...`는 현상 유지다.
- 플레이어를 놓치면 마지막 목격 위치까지 `!`로 이동한 뒤 `?`가 된다. 소리가 끝나면 소리 확인 이동은 멈추고 현 위치에서 `?`, 역치 이하가 지속되면 안정·복귀한다.
- 명시적 일시정지와 달리 의뢰창은 시간을 멈추지 않는다. 아이템 바 상시 표시·별도 인벤토리 창 없음. 맵은 제작하면서 결정한다.

- 길드와 연습장은 같은 씬이다. 현재 우선 구현은 의뢰 수락 여부와 무관한 길드 내 3D 1인칭 이동·시점 조작이다. 현재 의뢰는 한 개이며 수락 직후 이동하지 않는다. 연습장은 좌측 또는 우측에 배치한 선택 이용 공간이다. 수락 후 출구 직행 또는 연습 후 출구 문 상호작용으로 스테이지 1에 진입하며, 출발에 튜토리얼 완료를 요구하지 않는다.

- 연습장은 최초 튜토리얼뿐 아니라 새 능력을 얻을 때마다 의뢰 전에 시험할 수 있는 상시 선택 공간이다. 연습 여부와 실제 능력 획득은 구분하며 새 능력 연습도 출발 조건이 아니다.

## 아직 남은 규칙

- [ ] 주입 후 느린 이동 해제 시점을 정한다. 투척은 즉시 해제다.
- [ ] 같은 대상의 재생 중 중첩을 차단하는 입력 처리와 원래 관계 재추출 허용 시점을 정한다.
- [ ] 여러 높은 등급 소리가 동시에 발생할 때 가중치·동률 선택을 정한다.
- [ ] 수면 중 시야 판정과 벽·문·거리의 등급별 소리 전달 세부 처리를 정한다.
- [ ] 투척의 벽 충돌·공중 상태·유효 착지 처리와 최종 입력을 정한다.
- [ ] 스테이지 1 목표물·출구는 제작 중 조정한다. 현재 프로토타입은 가문의 인장 회수·입구 탈출이다. 저장 매개체는 후속 결정한다.
- [ ] 선택형 연습의 세부 안내 순서·대상 배치를 정한다. 연습 진행 기록은 출발 조건과 분리한다. 최초 기본 학습과 새 능력 획득 후 의뢰 전 연습을 모두 지원하는 방향은 확정이다.
- [ ] 연습 상태 초기화·구역 밖 이월·연습 대상 구성을 정한다.
- [x] 테이블 F 열람, ←/→ 문서 넘김, F/Enter 수락, 이동·시점 잠금, ESC 열람 종료를 사용한다. 성공은 길드 출입문 복귀, 실패는 수락 상태를 유지한 스테이지 전체 초기화다. 실제 의뢰 추가·해금·보상 저장은 후속이다.

## 추후 수치·제작 조정

등급별 보유 시간·증감 방향, 주입 유지·감쇠 시간, 누적 자극·역치 유지 시간, 기절·강제 경계 시간, 범위·거리는 추후 조정한다. 맵과 지정 오브젝트 배치는 제작하면서 결정한다.
