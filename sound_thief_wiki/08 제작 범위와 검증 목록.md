# 제작 범위와 검증 목록

아래는 미실행 제작·검증 항목이다. 새 규칙을 통합한 설계이며 구현·플레이테스트 완료 기록이 아니다.

## 제작 순서

1. 두 매개체의 소리 관계·등급·추출·원래 관계 무음을 구현한다.
2. 등급별 보유 시간·강제 느린 이동·초과 폭발을 구현한다. 소음과 플레이어 기절을 적용하고 폭발 자체로 게임 오버를 처리하지 않는다.
3. 오브젝트 주입·출력 감쇠·등급 0 복구와 직접 방출·즉시 복구를 구현한다.
4. 경비병의 수면과 등급·거리별 반응을 구현한다.
5. 중세 대저택 첫 스테이지와 상황별 튜토리얼을 연결한다.
6. 후속 의뢰·저장 매개체·소리 자체 절도로 확장한다.

사용 전 추가 추출은 막되 주입·방출 후에는 허용한다. 활성 주입 수는 제한하지 않는다. 레벨 지정 오브젝트만 상호작용하며 파괴 시스템은 없다. 직접 방출 기절 공격을 구현하고 HP·별도 인벤토리 창은 만들지 않는다.

## 시스템 검증

- [ ] 상호작용 가능 거리에서 두 매개체를 시각적으로 연결하고 발생 전 추출·무음화를 제공한다.
- [ ] 해당 관계의 모든 상호작용 소리를 묶어 제거하고 물리 기능은 유지한다.
- [ ] 사용 전 추가 추출은 불가능하고 주입·방출 후에는 가능하다.
- [ ] 이전 주입 출력 중에도 다른 대상의 추가 추출·주입은 가능하고 동일 대상의 재생 중 중첩은 차단된다.
- [ ] 같은 소리 등급이 소리 크기·경비 반응·보유 시간 결정에 일관되게 사용된다.
- [ ] 동일 등급에서 경비병까지 거리가 달라지면 설정한 반응 차이가 나타난다.
- [ ] 운반 중 강제 느린 이동과 등급별 제한 시간이 적용된다.
- [ ] 운반 중 등급이 유지된다.
- [ ] 제한 초과 시 소음과 플레이어 기절이 발생하며 폭발 자체로 게임 오버가 되지 않는다.
- [ ] 투척이 바닥에 떨어진 위치에서 폭발하며 범위 내 AI만 기절하고 벽 너머 기절은 차단된다.
- [ ] 발생한 소리 위치가 플레이어 이동을 따라가지 않는다.
- [ ] 시간 초과 자폭은 현재 플레이어 위치에서 발생하고 원래 소리 관계를 즉시 복구한다.
- [ ] 기절 중 움직임·모든 상호작용이 차단된다.
- [ ] AI 회복 후 패닉 강제 `?` 동안 시야·소리·기절 공격에도 상태를 고정한다.
- [ ] 패닉 해제 후 기절 공격이 다시 적용된다.
- [ ] HP와 주입 대상 파괴 시스템이 없다.
- [ ] 주입한 소리가 정해진 시간 출력 후 감쇠한다.
- [ ] 주입 출력 등급 0에서 원래 관계가 복구된다.
- [ ] 투척 즉시 느린 이동 해제·다음 추출 허용, 폭발 후 원래 관계 복구를 검증한다.
- [ ] 투척 후 기존 제한 시간이 계속되고 착지 전 만료 시 공중 투척물 위치에서 폭발한다.
- [ ] 만료·착지 폭발이 중복 발생하지 않는다.
- [ ] 벽 너머 소리 전달과 이산 등급 처리가 적용된다.
- [ ] 반복 자극이 누적되면 경비병이 깨어난다.
- [ ] 소리가 끝나면 이동을 멈춰 경계하고 역치 이하가 지속되면 원래 상태로 복귀한다.
- [ ] 일시정지 시 보유 타이머·감쇠·경비 시간이 멈춘다.
- [ ] 의뢰와 스테이지는 1:1이고 튜토리얼은 물건 획득 후 탈출해야 성공한다.
- [ ] 더 높은 등급의 소리만 현재 소리 확인 목표를 변경한다.
- [ ] 플레이어 인식 `!!` → 이탈 후 마지막 위치로 `!` → 도착 후 `?`를 검증한다.
- [ ] 발견은 추적 시작, 접촉은 즉시 실패·의뢰 전체 초기화다.
- [ ] 재시작 시 해당 의뢰의 모든 상태를 초기화한다.
- [ ] 의뢰창은 시간을 멈추지 않으며 아이템 바는 항상 표시된다.

## 첫 스테이지 검증

- [ ] 잠든 경비병·잠긴 문·열쇠 소리의 위험을 처음에 읽을 수 있다.
- [ ] 열쇠의 어떤 관계를 추출하는지 이해하고 조용히 문을 열 수 있다.
- [ ] 문 통과 후에도 추출 상태와 타이머가 유지된다.
- [ ] 느린 걸음으로 제한 시간 안에 주입 대상에 도달할 수 있다.
- [ ] 주입한 소리와 등급·거리별 경비 반응의 인과를 이해할 수 있다.
- [ ] 타이머·폭발 경고·주입 감쇠·관계 복구를 구분할 수 있다.
- [ ] 실제 행동과 목표 달성으로 안내·진행이 갱신된다.
- [ ] 튜토리얼의 각 행동을 이해하고 완료할 수 있는지, 실패 후 빠르게 재조작 가능한지 확인한다.
