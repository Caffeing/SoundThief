## 현재 구현 범위 — 길드 이동·튜토리얼·출발

길드와 연습장은 **같은 Unity 씬**이다. 길드의 3D 1인칭 이동을 기반으로 의뢰 한 개의 수락, 연습장 튜토리얼, 출구 문 상호작용에 의한 스테이지 1 진입까지 연결한다. 수락 여부와 무관하게 길드 이동은 가능해야 한다.

- [ ] 길드 씬을 열면 플레이어가 지정된 시작 위치에 생성된다.
- [ ] 의뢰를 수락하지 않아도 WASD 이동·마우스 시점 조작이 가능하다.
- [ ] 바닥과 벽의 충돌이 적용된다.
- [ ] 연습장 영역도 같은 씬에 구성하고 별도 씬 로딩을 요구하지 않는다.

- [ ] 현재 의뢰를 스테이지 1에 대응하는 한 개로 제공한다.
- [ ] 수락 직후에는 길드에 머무르고 씬을 자동 전환하지 않는다.
- [ ] 좌측 또는 우측 연습장에서 현재 기술을 선택적으로 연습할 수 있다.
- [ ] 의뢰 수락 후 연습 없이도 출구 문 상호작용으로 스테이지 1에 진입할 수 있다.
- [ ] 연습을 이용한 뒤에도 같은 출구 문으로 출발하며 튜토리얼 완료를 요구하지 않는다.
- [ ] 문에 접근하거나 튜토리얼이 끝난 것만으로 출발하지 않는다.

연습 초기화와 성공 후 길드 문 앞 복귀는 구현했다. 학습 기록은 출발 허가 조건이 아니다. 문서 목록은 확장 가능하고 준비 중 예시를 넘겨 볼 수 있으나 실제 수행 의뢰는 한 개다. 후속 의뢰·해금·보상 저장은 추가하지 않는다. 투척은 개발 보류로 공유 설정에서 비활성이며 보존 검사는 테스트 복제 설정에서만 켠다.

## 전체 후속 작업 목록

1. 두 매개체의 소리 관계·등급·추출·원래 관계 무음을 구현한다.
2. 등급별 보유 시간·강제 느린 이동·초과 폭발을 구현한다. 소음과 플레이어 기절을 적용하고 폭발 자체로 게임 오버를 처리하지 않는다.
3. 오브젝트 주입·출력 감쇠·등급 0 복구와 투척 방출·폭발 후 관계 복구를 구현한다.
4. 경비병의 수면과 등급·거리별 반응을 구현한다.
5. 저택을 스테이지 1로 정리하고 의뢰 수락 거점을 길드로 연결한다.
6. 길드 내 연습장에 기본 능력 학습을 분리하며 같은 시스템을 재사용한다.
7. 후속 의뢰·저장 매개체·소리 자체 절도로 확장한다.

사용 전 추가 추출은 막되 주입·방출 후에는 허용한다. 활성 주입 수는 제한하지 않는다. 레벨 지정 오브젝트만 상호작용하며 파괴 시스템은 없다. 직접 방출 기절 공격을 구현하고 HP·별도 인벤토리 창은 만들지 않는다.
