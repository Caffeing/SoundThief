# 화면과 소리 시각화

첫 저택은 남색 배경·청록 소리·붉은 위험을 기준으로 한다. 다른 세계의 미술은 별도로 확장하되 소리 상태 표시는 일관되게 유지한다.

## 3D 1인칭과 장소별 안내

마우스 시점·화면 중심 조준으로 거리 안의 대상을 선택하고 매개체 연결을 표시한다. 벽 너머 경비 위치를 모두 볼 수 있다는 전제를 두지 않으며 가시 범위의 상태 표시·소리 효과·HUD로 반응을 읽게 한다.

길드는 의뢰 안내, 연습장은 기본 능력 시험 안내, 스테이지 1은 실전 목표와 상황별 힌트를 제공한다. 기본 HUD·능력 규칙은 일관되게 유지한다.

## 테이블 문서 화면

테이블 위 종이 묶음에 F로 접근하면 한 의뢰의 본문과 간략한 설명만 표시한다. ←로 앞 문서를 옆으로 빼 뒤에 넣고 →로 뒤 문서를 옆으로 꺼내 앞에 덮는 순환 연출을 제공하고 현재 문서 번호·수락 가능/수락 완료/준비 중 상태를 구별한다. 전환 중에는 중복 넘김과 수락을 막는다. 열람 중 기본 조준·이동 HUD 대신 문서와 조작 안내를 표시한다. 이동·마우스 시점을 잠그며 ESC는 열람 종료에만 사용한다. 외부 이미지 없이 블록과 절차적 종이 메시·uGUI/TMP로 임시 구현한다.

## 필수 정보

| 정보 | 표시 방향 |
| --- | --- |
| 추출할 관계 | 상호작용 가능 거리에서 두 매개체의 시각적 연결·소리 출력 억제 표시 |
| 소리 등급 | 숫자·단계 표시와 파형을 함께 사용 |
| 원래 관계의 상태 | 정상 파형 / 추출 후 점선 연결 / 복구 표시 |
| 운반 | 추출한 소리·등급·남은 보유 시간·느린 운반 표시. 웅크리기는 Ctrl로 별도 조작 |
| 폭발 위험 | 제한 직전 타이머·파형·경고 변화. 정확한 경고 시점 미정 |
| 주입 | 대상 오브젝트·현재 출력 등급·유지 및 감쇠 상태 |
| 투척 방출 | 개발 보류·현재 비활성. 사용 전 궤적·예상 폭발/기절 범위는 표시하지 않음 |
| 경비병 | 수면·기절과 `!!` 인식 이동 / `!` 고정 위치 확인 / `?` 현 위치 경계 / `...` 현상 유지. 회복 후 패닉 강제 `?`와 기절 공격 면역 표시 |

등급은 소리 크기와 보유 제한에 공통으로 쓰므로 HUD에서 서로 다른 등급처럼 표현하지 않는다. 보유 타이머와 주입 감쇠 표시는 별도 상태로 구분한다.

아이템 바는 항상 표시하며 별도 인벤토리 창을 만들지 않는다. 의뢰 수행 중 의뢰창을 열어도 타이머·출력·경비 행동은 계속된다. 명시적 일시정지는 게임 시간을 멈춘다.

## 예측 가능성

관계 선택 시 어떤 소리가 없어지는지 최소 조준으로 알 수 있어야 한다. 사용 전 예상 반응·도달/기절 범위·투척 궤적·예상 폭발 위치는 사전 표시하지 않는다. 실제 사용 후 출력·복구·가시 범위 경비의 실제 상태로 관찰해 익힌다. 거리·벽·문 청각 감쇠와 순간음/지속음 AI 분리는 확정 기획이며 후속 구현 대상이다.

색상뿐 아니라 숫자·형태·텍스트로 상태를 구별한다. 안정적인 저장 매개체 획득 전에는 병이나 영구 인벤토리에 저장된 것처럼 표현하지 않는다.
