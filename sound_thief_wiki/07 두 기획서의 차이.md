# 기존 기획과 최신 통합 결정

## 우선순위

초초안의 3D 1인칭 잠입 퍼즐을 기반으로 한다. 스테이지 1은 튜토리얼 스테이지로 구성하고, 후속 사용자 설정과 소리 등급에 대한 최종 설명을 원문보다 우선한다. 원문은 보존한다.

| 항목 | 기존 적용 | 최신 통합 |
| --- | --- | --- |
| 세계·의뢰 | 저택 계약서 회수·탈출 | 여러 공간·세계·시간선의 의뢰. 초반 물건, 이후 소리 절도 |
| 추출 단위 | 문·시계 등 사물 전체 | 두 매개체의 상호작용 소리 관계 |
| 등급 | 별도 등급 없음 | 소리 크기. 경비 등 상호작용과 보유 시간에 동일 등급 사용 |
| 운반 | 조용한 기본 이동·시간 제한 없는 슬롯 | 추출 중 강제 느린 웅크리기·등급별 제한 시간 |
| 저장 | 초기부터 보관 슬롯 | 초기 일시 운반, 이후 저장 매개체 획득 |
| 사용 | 빈 바닥에 1초 예약 재생 | 오브젝트 주입 또는 직접 방출. 입력·지연은 재설계 |
| 복구 | 재생 종료 시 공급원 복구 | 주입 출력 등급 0에서 원래 관계 복구, 방출은 즉시 복구 |
| 초과 보유 | 없음 | 들리는 폭발음·플레이어 기절, 폭발 자체로 게임 오버 없음 |
| 첫 경비 | 순찰 | 중세 대저택에서 깊은 수면으로 시작 |
| 소리 반응 | 동일 반응·고정 2초 조사 | 소리 등급·거리·활동 상태에 맞춰 설계 |
| 튜토리얼 스테이지 | 문소리 채집·무음 통과·유인 | 열쇠 관계 추출·무음 개문·느린 운반·주입 경험 |

## 후속 답변으로 확정한 적용

의뢰·스테이지 1:1, 모든 상호작용 소리의 묶음 추출, 사용 후 재추출과 동시 주입 출력 허용, 운반 등급 유지, 벽 너머 소리 전달, 반복 자극 누적 기상, 확인 이동·경계·안정의 경비 행동을 적용한다. 방출은 투척 후 바닥 착지 지점의 범위 기절이며 벽에 막힌다. 들고 있을 때 시간 초과는 플레이어 위치의 소음·자기 기절·원래 관계 즉시 복구다. 투척 후에도 제한 시간이 계속되며 공중 만료 시 투척물 현재 위치에서 폭발한다. HP는 사용하지 않고 폭발 자체로 게임 오버가 되지 않는다. 주입 대상 파괴는 없다. 재시작은 의뢰 전체 초기화, 의뢰창은 시간 진행, 아이템 바 상시 표시를 적용한다. 맵은 제작 중 결정한다.

후속 답변으로 발생 전 거리 기반 추출·매개체 시각적 연결, 같은 대상의 재생 중 중첩 금지, 더 높은 등급의 소리로 목표 변경을 확정했다. 발견 시 `!!`, 놓치면 마지막 목격 위치로 `!` 이동 후 `?` 경계한다. 기절 중 이동·상호작용 봉인, 회복 후 n초 강제 `?` 동안 시야에 따른 `!!` 전환 금지를 적용한다. 튜토리얼은 물건 절도 후 탈출로 성공, 실패는 전체 초기화다. 발견 자체를 즉시 실패로 처리하던 기준은 대체한다.

최종 답변: 경비병과 접촉 즉시 실패·의뢰 전체 초기화. 투척 즉시 느린 이동 해제·재추출 허용, 원래 관계는 폭발 후 복구. 투척 후에도 기존 제한 시간 적용, 착지 전 만료 시 공중 투척물 현재 위치에서 폭발. AI 회복 후 패닉 강제 `?` 동안 모든 자극과 기절 공격에 상태를 고정하고 패닉 해제 후 기절을 다시 적용한다.

## 남은 미정 항목

높은 등급과 보유 시간의 증감 방향, 주입 시간과 등급의 수치 관계, 주입 후 이동 속도 전환 시점, 반응 대상 선택의 가중치, 저장 매개체 기능은 미정이다. [[09 미결정 사항]]에서 결정한다.

기존 3스테이지는 초반 제작 구조로 남기되, 계약서는 의뢰 목표물 후보로 전환한다. 튜토리얼의 단계별 진행과 주입 동선은 통합 설계 제안이다. 별도 시간표와 플레이 흐름 캔버스는 제거하고 튜토리얼 스테이지 문서로 통합했다.
