# 임무와 구역 구성

## 의뢰와 스테이지

**의뢰 하나에 스테이지 하나가 대응하는 1:1 구조**다. 의뢰를 수락하고 그 의뢰의 스테이지에서 목표를 수행해 완료한다. 하나의 의뢰를 여러 스테이지에 걸쳐 진행하지 않는다. 튜토리얼 역시 의뢰 하나를 받아 수행하는 스테이지다. 튜토리얼은 의뢰 물건을 훔친 뒤 밖으로 나와야 성공한다. 실패하면 해당 의뢰를 완전 초기화한다. 경비병과 플레이어가 닿는 즉시 실패한다. 별도 포획 동작 없이 해당 의뢰 전체를 초기화한다.

소리를 다루는 능력자가 의뢰를 받아 다른 공간·세계·시간선에 잠입한다. 초반 의뢰는 물건 절도, 이후 소리 자체 절도로 확장한다. 기존 계약서는 물건 목표의 후보이며 모든 의뢰의 공통 목표가 아니다.

## 초반 의뢰 구성

| 의뢰·스테이지 | 방향 | 상태 |
| --- | --- | --- |
| 1 튜토리얼 | 중세 대저택에서 잠든 경비병과 열쇠 소리를 다루며 의뢰 수행 | 물건 절도 후 탈출로 성공. 구체적 목표물·출구는 제작 시 결정 |
| 2 | 소리 운반·주입과 경비 반응을 활용하는 후속 의뢰 | 내용 미정 |
| 3 | 무음화·유인을 결합하는 물건 절도 의뢰 | 계약서 목표는 후보 |
| 이후 | 다른 세계·시간선, 저장 매개체 획득, 소리 절도 의뢰 | 순서·내용 미정 |

초반 3개는 구성 방향이며 전체 의뢰 수를 제한하지 않는다. 각 행은 독립된 의뢰와 그에 대응하는 스테이지다.

## 레벨 제작

튜토리얼 맵의 동선·배치·오브젝트는 실제 제작하면서 결정한다. 기존 입구·복도·주입 장소 등의 예시는 확정 맵이 아니다. 레벨 디자인에서 지정한 특정 오브젝트만 소리 상호작용 대상으로 사용하며 주입 대상 파괴 시스템은 만들지 않는다.

튜토리얼의 문 통과는 같은 의뢰 안의 연속 플레이이므로 관계·보유 시간·경비 상태를 초기화하지 않는다.

## 재시작과 시간

**재시작은 해당 의뢰의 모든 상태를 처음으로 초기화**한다. 위치·문·잠금·아이템·소리 관계·운반·주입·경비·기절·타이머·의뢰 진행·튜토리얼 기록이 포함된다. 부분 체크포인트 재시작을 사용하지 않는다.

명시적 일시정지 기능은 제공하며 게임 시간을 멈춘다. 의뢰 수행 중 의뢰창을 여는 행동은 일시정지가 아니므로 보유 시간·출력 감쇠·경비 행동 등이 계속 진행된다. 별도 인벤토리 창은 없고 아이템 바를 항상 표시한다.
