# 스테이지 1 사물 강조·경비 표시 개선

## 2026-10-30 상시 강조 제거 후속

소리 사물은 평소에 강조하지 않는다. 상호작용 거리에서 직접 조준한 사물 하나에만 얇고 반투명한 황동색 테두리를 0.15초에 걸쳐 표시하고, 시선을 떼면 사라진다. 무음·주입 상태는 기존 상호작용 안내와 실제 소리 반응으로 읽는다. 파란색 테두리와 평상시 연결선은 제거하고, 추출·주입에 성공한 직후에만 0.3초 연결 효과를 사용한다.

경비 시야는 상시 표시하지 않는다. 10m 이내에서 벽에 가리지 않은 활동 중 경비를 약 0.4초 동안 직접 바라보면, 현재 시야가 바닥에 옅은 적갈색으로 1.4초 동안 나타나고 사라진다. 계속 바라봐도 상시 표시로 이어지지 않는다. 시선을 0.25초 이상 뗐다가 다시 관찰하면 재확인할 수 있다. 벽·가구·닫힌 문 차폐와 수면·기절·패닉 시 숨김을 유지한다. 실제 감지 판정은 바꾸지 않는다.

현재 한국어 하이어라키와 짧은 검증 결과는 hierarchy-and-feedback.md를 따른다. 아래의 이전 청록색/상시 시야 기록은 변경 이력이다.

## 적용 범위

1. 소리를 다룰 수 있는 사물에 실제 모델의 외곽선을 표시한다. 10m 이내에서 청록색으로 표시하고, 조준하면 밝은 황금색, 주입 대기/출력 중이면 주황색, 원래 관계가 무음이면 흐린 청록색으로 구분한다. 벽 뒤를 투시하는 표시는 제공하지 않는다. 충돌체나 길찾기에는 관여하지 않는다.
2. 현관 여행 상자, 복도 탁자, 서재 문서함, 식당 배식장, 식기 더미에 소리 추출·주입·두드리기/건드리기 기능을 더한다. 두 열쇠의 취득에도 금속 관계 소리를 지정한다. 기존 문·시계·갑옷·물병·인장을 포함해 소리 사물 15개를 표시한다. 장식 가구의 기능 추가이며 모두 새 모델을 만들었다는 뜻은 아니다.
3. 서재 경비는 세 근무 지점을 순찰하고 지점에서 2.5초 대기한다. 유인·추적·경계 후 근무로 복귀하며 발소리로 움직임을 들을 수 있다. 다른 경비의 수면 시작 설정은 유지한다.
4. 활동 중인 경비의 현재 시야를 바닥에 반투명 빨간 부채꼴로 표시한다. 실제 시야 거리·각도를 읽고 눈높이에서 벽·가구·닫힌 문에 막힌 부분을 잘라낸다. 수면·기절·패닉에는 실제 시야 판정을 하지 않으므로 표시하지 않는다. 이전의 최소 안내 방향에 대한 사용자의 최신 요청이며 소리 도달 범위나 예상 유인 결과 표시를 추가하지 않는다.
5. 부풀려진 스킨 렌더러 범위 대신 실제로 변형된 머리 꼭짓점으로 투구 크기와 위치를 맞춘다. 머리 위에 걸친 상태에서 상부 머리를 감싸도록 낮추고 앞쪽 정수리가 뚫리지 않게 높이를 보정하며, 머리뼈 자식 관계를 유지해 애니메이션을 따라간다.

## 동선과 공통 기반

서재 중앙 책장 때문에 접근 위치가 달라진 부분은 실제로 책장을 피해서 조준하도록 검증 경로를 갱신한다. 눈높이 충돌을 추가한 갑옷이 식당 서쪽 통로를 좁히던 문제는 갑옷을 앞쪽 모서리로 옮겨 해결하고 이동망을 다시 생성한다. 현재 이동망은 ManorReadableStealthNavMesh.asset이다.

SoundObjectOutline·GuardVisionCone은 필요한 씬에 붙이는 선택 컴포넌트다. 기존 다른 팀원 씬이나 공통 렌더러 설정을 바꾸지 않는다. 두 셰이더와 재질은 Assets/SoundThief 안에서 관리한다. 표시용 메시에는 Collider를 만들지 않는다.

## 검증

전체 잠입·공통 기반 검사에 외곽선 생성/셰이더 지원, 잠든 경비의 시야 숨김, 벽에 의한 바닥 시야 차단, 투구의 실제 머리 높이 적합성을 추가했다. 최종 결과와 실행 화면 근거는 아래에 기록한다. 자동 검사 통과와 사용자가 느끼는 재미·표시 강도 평가는 구분한다.

## 최종 구현 검증 (2026-10-30)

PlayMode **38/38 통과**(186.51초, 실패·건너뜀 0). 시계와 남쪽 물병을 각각 이용한 서재 열쇠 회수, 활동 중인 경비와 실제 이동 속도를 적용한 인장 회수·귀환, 공통 기반, 투척 비활성, 순간음·지속음 조사, 벽·문 감쇠와 자동 닫힘을 확인했다. 비볼록 가구 메시에서도 청각 계산 경고 없이 동작하도록 회귀 검사를 보완했다.

소리 사물 15개에 외곽선이 생성되고, 활동 중인 경비만 빨간 시야가 표시되며, 벽 차폐·기절 시 숨김이 동작한다. 투구는 실제 머리 표면과 앞쪽 정수리 여유를 고려해 세 경비 모두 맞췄다. 최종 이동망은 ManorReadableStealthNavMesh.asset이다.

실행 중 프레임 1→2034, 게임 시간 0.00→42.25초 증가와 서재 경비의 Patrolling 상태를 확인했다. 그 뒤 근접 시각 점검용으로 일시 정지한 실행 씬에서 외곽선·시야·투구 사진을 촬영했다. 사진은 사용자 키보드 완주 기록이 아니다. 최종 실행 콘솔과 근거는 stage1-stealth-verification.json, 검사 원본은 stage1-stealth-test-results.json에 저장한다.

자동 검사는 동작·경로 가능성을 확인한다. 재미와 표시 강도·초회 난이도 평가는 사용자 플레이를 통해 조정한다.
