# 스테이지 1 핵심 플레이 재설계 검토

2026-10-29 · 사용자 피드백: 재미가 없고 현재 구조가 게임 컨셉을 충분히 담지 못한다.

상태: 사용자가 「소리를 옮겨 경비 동선과 침입 기회를 스스로 만드는 잠입」 방향을 선택하고 개선을 지시했다. 아래 진단·제안 이력을 바탕으로 첫 구현을 진행한다. 실제 적용 범위는 문서 끝의 구현 기록을 따른다.

## 현재 구현에서 확인한 문제

1. 진행의 중심이 현관 열쇠 → 서재 열쇠 → 식당 인장이다. 선행 조건은 있지만 소리를 어떤 이유로 훔치고 어디로 옮길지 선택하는 상황은 약하다.
2. 모든 경비는 수면 상태로 시작하며, 수면 중 시야 확인을 하지 않는다. 평상시 순찰도 없다. 플레이어가 행동하기 전 관찰하고 이용할 경비 동선이 부족하다. 근거: GuardAgent.cs.
3. 열쇠·인장 획득은 소리 관계를 거치지 않고 즉시 인벤토리에 들어간다. 절도 과정에서 능력의 가치를 체감할 장면이 부족하다. 근거: ThiefInteractable.cs.
4. 열린 문은 열린 채 유지된다. 원래 관계가 복구되어도 이미 열린 문을 걸어서 통과하면 새 문 소리가 나지 않는다. 따라서 복구 타이머 자체만으로 귀환의 긴장감이 생긴다고 볼 수 없다.
5. 소리 재생은 사물의 종류 대신 등급별 합성음을 선택한다. 문에서 뽑은 소리가 다른 장소에서 들린다는 정체성을 듣고 확인하기 어렵다. 근거: SoundWorld.cs.
6. 벽·닫힌 문에 따른 청각 감쇠와 순간음/지속음 조사 행동은 기획만 확정되고 구현되지 않았다. 공간을 이해하고 소리의 결과를 학습할 기반이 부족하다.

가구 밀도와 화면 품질 개선으로 이 문제들이 해결되지는 않는다. 기존 자동 검사 통과는 기능·경로의 회귀 검증이며 재미의 검증 결과가 아니다.

## 재설계의 목표

플레이어가 주변을 관찰해 소리의 원인과 위험을 이해하고, **원래 행동을 조용하게 만들기 → 위험을 안고 운반하기 → 다른 위치에 소리를 배치하기 → 열린 기회를 이용하기 → 원래 관계 복구에 대응하기**를 하나의 상황으로 경험하게 한다.

기존 확정 사항인 관계 단위 추출, 손에 소리 하나, 운반 중 느린 이동과 제한 시간, 문 주입 가능, 주입 후 3초 지연, 출력 종료 시 원래 관계 복구, 투척 보류는 유지한다. 서재의 선행 보상으로 식당을 열고 두 방 모두 위험과 보상이 있는 방향도 유지한다.

## 추천안: 소리로 침입 기회를 만드는 잠입

큰 중앙 홀 양옆에 독립된 방을 붙이는 구성에서, 현관 → 서재 → 연결 통로 → 식당 → 현관으로 이어지는 짧은 순환 동선을 우선 검토한다. 열쇠 선행 조건은 유지하되 경비가 지키는 통과 구간과 우회로를 배치한다. 방 크기는 운반 거리·관찰 지점·엄폐·경비가 비우는 시간으로 정한다.

첫 시험 구간은 문 하나·활동 중인 경비 하나·소리를 놓을 후보 두 곳·목표 상호작용 하나로 제한한다. 기존 에셋을 사용하고 전체 맵 재장식에 앞서 이 구간의 재미를 확인한다.

- 관찰: 엄폐한 상태에서 경비의 위치/이동과 위험한 문을 함께 볼 수 있다. 일부 경비의 평상시 근무/순찰은 추가 제안이며 모든 경비를 자동으로 순찰 상태로 바꾸는 확정은 아니다.
- 진입: 문 관계를 추출하면 실제 빗장·경첩 소리가 사라지는 차이를 들을 수 있다. 열쇠 조건은 그대로 적용한다.
- 배치: 가까운 대상은 빨리 손을 비울 수 있지만 경비의 조사 지점이 통로와 겹친다. 더 돌아간 대상은 운반 위험이 커지는 대신 통과 구간을 더 멀리 비울 수 있다. 두 선택의 실제 안전성은 시야·길찾기·소리 감쇠로 검증한다.
- 행동: 주입 후 3초를 이용해 시야 밖으로 이동하고, 경비가 확인하러 떠난 기회에 서재 열쇠 또는 식당 목표에 접근한다.
- 추가 선택: 인장을 보관한 진열장의 쇠걸쇠 등, 절도 과정에 소리 관계가 있는 상호작용을 제안한다. 손에 소리가 남아 있다면 이를 먼저 처리해야 다음 관계를 추출할 수 있다. 능력을 사용했는지 세는 별도 체크 대신 상황의 위험과 손 점유 규칙으로 선택을 만든다.
- 귀환: 진입 때 만든 소리 배치와 경비 이동이 돌아가는 길에 영향을 줘야 한다. 일부 문의 자동 닫힘 또는 경비가 열린 문을 닫는 행동은 이를 만들 후보이며 추가 결정·검증 대상이다. **무음 관계 복구만으로 문이 닫히거나 저절로 소리가 나는 것으로 취급하지 않는다.**

## 공통 기반에 필요한 최소 요소

| 요소 | 역할 | 범위 |

| 사물/관계별 소리 식별과 클립 | 무엇을 훔쳤는지, 어디로 옮겼는지 귀로 확인 | 기존 등급·타이머를 보존하는 공통 소리 데이터 |
| 거리·벽·닫힌 문 감쇠 | 방과 문이 청각적으로 의미를 갖게 함 | 이미 확정된 규칙 구현 |
| 순간음/지속음 조사 분리 | 짧은 소리를 듣고도 확인 지점까지 가는 일관성 | 이미 확정된 규칙 구현 |

## 제작·평가 순서

1. 짧은 구간에서 소리 정체성·공간 감쇠·경비 조사 반응을 먼저 맞춘다.
2. 두 가지 주입 위치와 접근 방식으로 각각 목표를 회수할 수 있는지 직접 플레이한다. 하나의 고정 해법만 성립하면 선택지를 다시 배치한다.
3. 사용자가 소리를 훔친 이유와 그 결과를 설명할 수 있는지, 3초 동안 무엇을 할지 선택하는지, 실패 원인을 관찰로 납득할 수 있는지 확인한다.
4. 이 구간이 성립한 뒤 서재→식당의 전체 동선으로 확장한다. 미술 리소스는 기존 작업을 재사용한다.

규칙을 이해하지 못한 실패, 느린 이동만 길게 강요하는 구간, 주입 후 목적 없이 기다리는 구간, 열린 문 때문에 복구가 무의미한 귀환을 개선 대상으로 삼는다. 자동 검사에 더해 짧은 사용자 플레이로 다음 확장 여부를 판단한다.


## 첫 개선 구현 (2026-10-29)

- 서재 경비에 깨어 있는 근무 시작, 세 순찰 지점과 2.5초 대기를 적용했다. 수면 시작을 선택하는 공통 기능은 유지한다.
- 시계 외에 서재 남쪽의 황동 물병을 주입 대상으로 추가했다. 식당 인장 가까이에도 물병을 배치해 다른 곳에서 재생 중인 소리를 기다리지 않고 독립적으로 손을 비울 수 있다.
- 인장 취득에 「손↔인장과 금속 받침대」 3등급 관계를 연결했다. 미리 추출하면 조용히 취득하고, 그러지 않으면 그 장소에 순간음이 난다.
- 저택 세 문에 8초 자동 닫힘과 통과 중 닫힘 방지를 적용했다. 무음 복구 자체가 소리를 만드는 것은 아니며 여닫는 행동이 소리를 만든다. 다른 씬의 문은 autoCloseSeconds=0이면 기존 동작을 유지한다.
- 구조 벽 24개에 SoundBarrier를 지정했다. 가청 범위는 벽별 0.65·닫힌 문별 0.55를 곱하며 원래 등급은 유지한다. 감쇠는 초기 조정값이다.
- 순간음은 발생 위치 또는 갈 수 있는 경로 끝까지 확인한다. 지속음은 종료·거리·차폐로 청각을 잃으면 현재 위치에서 멈춰 경계한다.
- 관계별 음색에 Kenney Impact Sounds(CC0) 원본을 사용한다. 주입은 훔친 관계의 클립을 유지한다. 시계의 평상시 틱은 관계 추출 시 사라지고 복구 시 돌아오는 익숙한 환경음이다.
- 추가 가구 충돌에 맞춘 ManorCoreLoopDiningNavMesh.asset을 사용한다. 당시 중간 이동망이며, 최종 동선 검증과 현재 이동망은 아래 최종 기록을 따른다.


## 2026-10-30 관찰과 엄폐 보완

물병 경로에서 경비에게 곧바로 노출되던 문제를 확인해 서재 중앙에 높은 관찰용 책장을 배치하고 실제 시야·충돌·이동망을 맞췄다. 양쪽 통로 중 경비가 이용하는 쪽을 보고 반대쪽으로 이동할 수 있다. 시계와 갑옷의 충돌도 모델 높이에 맞춰 눈높이 시야를 차단한다.

경비가 걸을 때 방향성 발소리를 들려준다. 익숙한 근무 발소리는 경비끼리 서로를 깨우는 자극으로 사용하지 않는다. 저택 전용 설정 ManorStealthRules.asset은 1/2/3등급 보유 시간을 30/24/12초로 조정했다. 기존 공통 PrototypeRules와 다른 팀원 씬의 수치는 변경하지 않는다. 소리를 든 뒤 무조건 달려 들어가는 대신 관찰할 여유를 확보하기 위한 초기 조정값이다.

## 최종 구현 검증 (2026-10-30)

PlayMode **38/38 통과**(186.51초, 실패·건너뜀 0). 시계와 남쪽 물병을 각각 이용한 서재 열쇠 회수, 활동 중인 경비와 실제 이동 속도를 적용한 인장 회수·귀환, 공통 기반, 투척 비활성, 순간음·지속음 조사, 벽·문 감쇠와 자동 닫힘을 확인했다. 비볼록 가구 메시에서도 청각 계산 경고 없이 동작하도록 회귀 검사를 보완했다.

소리 사물 15개에 외곽선이 생성되고, 활동 중인 경비만 빨간 시야가 표시되며, 벽 차폐·기절 시 숨김이 동작한다. 투구는 실제 머리 표면과 앞쪽 정수리 여유를 고려해 세 경비 모두 맞췄다. 최종 이동망은 ManorReadableStealthNavMesh.asset이다.

실행 중 프레임 1→2034, 게임 시간 0.00→42.25초 증가와 서재 경비의 Patrolling 상태를 확인했다. 그 뒤 근접 시각 점검용으로 일시 정지한 실행 씬에서 외곽선·시야·투구 사진을 촬영했다. 사진은 사용자 키보드 완주 기록이 아니다. 최종 실행 콘솔과 근거는 stage1-stealth-verification.json, 검사 원본은 stage1-stealth-test-results.json에 저장한다.

자동 검사는 동작·경로 가능성을 확인한다. 재미와 표시 강도·초회 난이도 평가는 사용자 플레이를 통해 조정한다.
